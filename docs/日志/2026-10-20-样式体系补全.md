# 2026-10-20 · 样式体系补全

> token 只是"值"，补上命名、布局原语、状态约定、覆盖出口四条规则才算体系

## 背景

已经有 `tokens.css` 和 style-guard 禁止硬编码，但被问了一句"CSS 只是不能硬编码么，它是体系么"，检查后发现只解决了"值"，没解决"规则"：

- 类名三种风格并存：`g-btn`（缩写）、`modal__body`（BEM 无前缀）、`content`/`glyph`（无前缀通用名）
- 全项目只有 1 处 focus 样式，键盘操作没有焦点提示
- `display:flex;flex-direction:column;min-height:0;overflow:hidden` 在三个文件里重复
- **scoped 特异性 0,2,0，全局 0,1,0 覆盖不了**，组件内部样式外部改不动

## 做了什么

- 命名规则：`g-` 通用组件 / 页面名 / `u-` utility，元素 `__`，状态 `.is-*`，禁止无前缀通用名
- `layout.css`：`.u-stack` `.u-row` `.u-fill` `.u-center` `.u-scroll` `.u-gap-1..6`
- 状态约定表 + 全局 `:focus-visible`（2px `--accent`）
- 组件级 token 出口：`--modal-body-padding` `--page-header-height` `--toast-max-width`
- ADR-11：CSS 内联进 JS 是故意的（file:// 少一次请求）

## 为什么

token 解决"值是多少"，体系解决"怎么用"。有词典不等于会说话。

覆盖出口是核心：scoped 下**变量是唯一的覆盖方式**，不留出口就等于组件样式永久封闭。

## 影响 / 后续

- 明确不做：`@layer`（没有 utilities 层用不上）、原子化 CSS、容器查询（Chromium 105+，CEP 12 是 99）
- 现有组件里 `.content` `.glyph` 这类无前缀类名还没全部改掉，重构时顺手换
