# 字体面板（/fontSet）返工复盘

> **范围**：只描述 **`/fontSet` 这一页**。文中的 `#222`、`#535353`、`26px`、`10px`、`30px`
> 都是这一页在原版里的实际值，**其他页面不要照抄**。
>
> **可以借鉴的是"排查思路"**（第 0 节），不是这些结论。换一个页面，必须重新走
> `render 行号 → 真实 class → scoped CSS → 计算/测试`，不能拿本文的值套。

---

## 0. 可迁移的排查思路（任何页面都适用）

按顺序，不要跳步：

1. **先排除旧产物**
   源码 mtime 和 CEP 产物 mtime 对一下；确认 `npm run build` 真的执行完。
   不要拿旧包截图当证据。

2. **先找原版 render，再查 CSS**
   `app.v4.js` 里的 render 行号 → 真实 class（含 `f-*`/`app-padding` 这种通用类）
   → `app.bf68b505.css` 里带 `[data-v-*]` 的规则。
   不从截图估、不从组件名猜。

3. **布局**
   - 根节点和子节点只能有一层水平 padding；背景整宽、内容内缩是允许的。
   - 多列按钮把总宽算到 100%（列宽 + gap/margin 一起算）。
   - 行距/底部间距看按钮的 `margin-bottom`，不能只看容器 `padding-bottom`。
   - 用原版行号 + CSS 值解释"为什么"，不要用"看起来对齐"。

4. **状态**
   - hover / selected 是否同一套背景+边框语言；
   - 是否改了图标 `color`；
   - 是否把别的组件的规则（比如 `.hover`、`div-vision`）搬到当前组件。

5. **数据链路**
   - mount 时手动读成功 ≠ 事件链路通；
   - 事件 ID 用原版写死的十进制，不要多转一道；
   - 回调里的 `eventID` 要能和注册时的 key 对上；
   - 事件注册失败必须能降级，不能整页崩。

6. **写后同步**
   - 原版写操作是本地乐观更新；
   - 只有 `selectLayer` 的明确调用点才回读；
   - 新增回读前先数一遍调用点。

7. **默认值 / 开关**
   - 看 `data()` 初值 + `settings` 默认；
   - 不要凭"点一下应该关闭"设计交互。

8. **颜色**
   - 按元素的 scoped 规则取色；
   - 页面底色、面板底色、控件底色、按钮底色分开；
   - 不要拿通用输入色 token 顶替面板专用色。

9. **图标 / 角标**
   - 位置、尺寸、颜色、旋转都按 render 子节点和 CSS；
   - 不要先放右上角再旋转 180°。

10. **改完必须重新 build，再看效果**
    门禁：`npm run check` / `vue-tsc` / `npm test`。

## 1. 本页犯过的错（只针对 /fontSet）

### 1.1 旧产物

- 源码 14:01、产物 13:55，还拿旧包截图继续改。
- 自查：`(Get-Item src/...).LastWriteTime` vs 扩展目录 `index.html`。

### 1.2 重复 padding

- 误以为原版 `.app-padding` 只有左 padding；实际是 `box-sizing:border-box;padding:0 10px`。
- `FontHierarchy` 根 `0 10` + `smart-body` 再 `10` = 20；原版根 0，各区块自己 10。
- `fontset__scroll` 10 + `fontset-color` 10 = 20；原版各行自己 10。
- 预设块背景整宽 + 内部 10 是对的，不要为了"对齐"把背景也缩进去。

### 1.3 6 列宽度

- `calc(16.66667% - 6px)` + `gap:6px` → 总宽少 6px，右边多空 6px。
- 原版：`.btn-small-6{width:calc(16.66667% - 5px)}` + `margin-right:6px`（最后一个 0）。
- 6 列：`6×(16.66667% - 5px) + 5×6px = 100%`。

### 1.4 预设底部

- 只写 `padding-bottom:3px`，漏了按钮 `mb8`。
- 原版：行距 8、最后一行到底 8+3=11。

### 1.5 hover / selected

- 自创 `--accent` 蓝色选中态。
- 原版 `baseIcon`：
  ```css
  .base-icon { width:26px; height:26px; border:1px solid transparent }
  .base-icon:hover { background:rgba(0,0,0,.2); border-color:#444 }
  .select { background:#222; border-color:#444 }
  ```
- 把 `div-vision` 的 `.hover{padding:2px}` 错套到 `baseIcon`。
- 把 `svgWidth 20` 当按钮尺寸，写成 20×20。

### 1.6 事件不刷新

- 用 `charIDToTypeID("slct")` 转 ID；原版 `$psEvent.add("1936483188", …)` 直接写死十进制。
- 只验证 mount 读取，就以为事件通。
- `startTextInfoWatch` 先读后订阅；PS 未 ready 时第一次读失败，后面没有事件补。
- 本页事件：`1936483188 / 1416785510 / 1298866208 / 1936028772`。

### 1.7 写后回读

- `fontSize / leading / tracking / color / styleToggle / textAlign / hierarchySize`
  写成功后都加了 `refreshTextInfo()`。
- 原版只有：mount、导航切页、4 个 PS 事件、换家族、快捷字体应用 才回读。

### 1.8 默认值 / 开关

- `pickPreset` 里把 `presetOpen[index] = false`，点预设就关面板。
- 原版 `ztExpandMultiple` 默认 true；点预设按钮不关，只有箭头 toggle。
- `fontSpacingIstrue: -1`、`fontSpacingIstrueArr: [false,false,false]`。

### 1.9 颜色

本页专用值（**不要外推**）：

| 元素 | /fontSet 原版 |
|---|---|
| 页面 | `#363636` |
| 预设组 / 智能排版 / 层级面板 | `#222` |
| `base-input` / `base-dropdown` | `#222`，透明边框，radius 5 |
| `btn-small` / `btn-2` | 全局 `button` #535353，hover #444，无边框 |
| `hierarchy-layout-input` | `#111` |
| 文字 | `#c3c3c3` |

之前的错：输入/下拉用 `#2c2c2c`；按钮用 `#2c2c2c`；层级输入用 `#2c2c2c`；
快选字体行做成深色下拉（原版是透明居中 `baseOpen`）。

### 1.10 角标

- 右上角、蓝色、9px、旋转 180°。
- 原版：右下角、跟随图标灰、4px（`svg-4`）、不旋转；
  它是 `baseIcon` 的第二个 flex 子项（`svg-4 mt12`），不是绝对定位。
