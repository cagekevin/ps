# 字体面板 · 事件数据流 / 契约 / 落点

> 目的：把“PS 里选中文字图层 → 面板显示该图层属性”定成一条**单向数据流**。
> 所有行号来自 `docs/原版/01-原版源码/panel/js/app.v4.js`，不写猜测值。

## 一、数据流

```
Photoshop
  │  slct / Trnf / Mk / setd
  ▼
CEP: com.adobe.PhotoshopJSONCallback<extensionId>
  │  e.data = "<5 字符前缀> + JSON"
  ▼
cep/events.ts
  │  decodeEventPayload：e.data.substring(5) → { value:{ eventID, eventData } }
  │    （失败是判别联合：不是字符串 / 不是合法 JSON / 不是对象 ⇒ 记日志并丢弃这一次事件）
  │  按 eventID 分发（全局 100ms 节流，原版 listedHandle）
  ├──────────────► selection/index.ts
  │                  selectionRef = { hasSelection, typeNumber }
  │
  └──────────────► selection/current-text.ts
                     │  按原版条件过滤事件
                     │  refreshTextInfo()
                     ▼
                   jsx.font.getFontSimpleInfo()
                     │  { err, data?, msg? }
                     ▼
                   asJsxResult → normalizeTextInfo
                     │  TextInfo
                     ▼
                   textInfoRef（唯一响应式快照）
                     ▼
                   stores/font-set.ts
                     │  textInfo = computed(textInfoRef)
                     ▼
                   FontColor.vue / FontHierarchy.vue
```

写操作是另一条单向流，不回头读：

```
FontColor emit
  → page useCommand
  → commands/fontSet.ts
  → jsx.font.setXxx()
  → applyTextPatch()（只改 textInfoRef）
```

例外（原版本来就会回读）：
- `fontName.kind === 'family'`：原版 `setFontFamily → selectLayer`；
- 快捷字体 apply：原版 `changeFont → selectLayer`。

## 二、事件契约

### 2.1 事件 ID（原版 `openPsEvent`，42472-42476）

| 语义 | 十进制 | 原版过滤条件 | 行号 |
|---|---|---|---|
| `selection` | `1936483188` | `eventData.layerID.length == 1` 才 `ztSelectLayer` | 69427-69436 |
| `transform` | `1416785510` | 无条件 | 69460-69461 |
| `make` | `1298866208` | `eventData.null._ref === "textLayer"` | 69448-69452 |
| `setd` | `1936028772` | `eventData.to._obj === "textStyle"` | 69412-69419 |

> `slct` 多选时不刷新单层文字属性；这是原版行为，不是缺陷。

### 2.2 回调 payload

```ts
export interface PhotoshopEventPayload {
  eventID: number
  eventData: {
    /** slct：选中的图层 ID 列表；原版只在长度 1 时读文字属性 */
    layerID?: number[]
    documentID?: number
    /** Mk：null._ref === 'textLayer' */
    null?: { _ref?: string; _property?: string }
    /** setd：to._obj === 'textStyle' */
    to?: { _obj?: string }
    [key: string]: unknown
  }
}
```

- 回调类型：`com.adobe.PhotoshopJSONCallback${extensionId}`；
- 解码：`JSON.parse(e.data.substring(5))`；
- 节流：全局 100ms，窗口内后续事件**直接丢弃**（原版 `listedHandle`，不是排队去抖）；
- 注册对象：`{ type, scope:'APPLICATION', appId:undefined, extensionId, data:十进制字符串 }`；
- 不 stringify、不补 `appId`。

### 2.3 注册/监听契约

- `ensureCallback()` 必须先安装监听，成功后再置 `callbackInstalled=true`；
- `register(name)` 失败必须抛，不允许返回 no-op；
- `subscribeHostEvent` 注册失败必须回滚 listener；
- `registered` 表示宿主事件已注册，进程内只注册一次；
- 页面卸载只移除 listener，不注销宿主事件；重新进页面直接复用注册。

## 三、读取契约

`zt_getFontSimpleInfo` 返回：

```ts
type JsxResult<T> =
  | { err: 0; data: T }
  | { err: number; msg?: string }
```

`TextInfo` 字段（原版 `selectLayer` 直接 `fontInfo = data`）：

```ts
interface TextInfo {
  size: string          // 带单位，如 "12 点"
  weight: string
  fauxBold: boolean
  fauxItalic: boolean
  useAutoLeading: boolean
  leading: number
  tracking: number
  autoKerning: string   // manual | opticalKern
  capitalization: string
  color: { r: number; g: number; b: number }
  family: string
  justification: string // left | center | right
}
```

- `err !== 0`：不覆盖 `textInfoRef`，只写 `textInfoError`；
- `err === 0`：整份覆盖，不做字段级兜底；
- 不在读取层补单位、不拆双层 JSON、不兼容数组颜色；这些不属于契约。

## 四、落点

| 层 | 文件 | 职责 | 禁止 |
|---|---|---|---|
| 传输 | `src/cep/events.ts` | CEP 事件注册、解码、按 ID 分发、100ms 节流 | 不写业务过滤、不读文字属性 |
| 选区 | `src/selection/index.ts` | `selection` 事件 → `selectionRef`；命令禁用态 | 不读 `zt_getFontSimpleInfo` |
| 文字属性 | `src/selection/current-text.ts` | 4 个事件过滤、`refreshTextInfo`、`TextInfo` 归一 | 不直接改 store、不写 jsx |
| 投影 | `src/stores/font-set.ts` | `textInfo` / `textError` / `typeUnits` 只读投影 | 不订阅事件、不写 jsx |
| 页面 | `src/pages/fontSet/index.vue` | `startTextInfoWatch()` 启停；不碰事件细节 | 不直接 `subscribeHostEvent` |
| 写命令 | `src/commands/fontSet.ts` | jsx 写 + `applyTextPatch` 乐观更新 | 写后不回读（family/quick 例外） |

### 4.1 事件过滤落点

`selection/current-text.ts` 的监听器必须按 2.1 过滤，而不是四个事件一律读：

```ts
subscribeHostEvent(name, (payload) => {
  if (name === 'selection') {
    const ids = payload.eventData?.layerID
    if (!Array.isArray(ids) || ids.length !== 1) return
  }
  if (name === 'make' && payload.eventData?.null?._ref !== 'textLayer') return
  if (name === 'setd' && payload.eventData?.to?._obj !== 'textStyle') return
  void refreshTextInfo()
})
```

### 4.2 生命周期落点

`pages/fontSet/index.vue`：

```
onMounted:
  stopTextWatch = startTextInfoWatch()   // 失败可见，但不阻断 store.load
onBeforeUnmount:
  stopTextWatch?.()
  stopTextWatch = null
```

`current-text.ts` 不保留模块级 `stopWatch`；每次调用返回自己的 stop，避免“上一次的 stop 把新页面订阅挡住”。

## 五、诊断契约

日志必须能区分四步，缺一不可：

1. `PS 事件注册完成`（注册对象已发出）
2. `回调监听已安装`（`addEventListener` 已执行）
3. `收到 PS 回调`（CEP 真的派发）
4. `分发宿主事件` / `文字属性已更新`（业务链走到）

如果只有 1、2，没有 3：问题在 CEP 桥或宿主注册，不在 `selectLayer`。
如果有 3 没有 4：问题在 `eventID` 映射或事件过滤。
如果有 4 没有 `文字属性已更新`：问题在 `zt_getFontSimpleInfo` 返回。

## 六、验收顺序

1. 打开面板，确认日志有“回调监听已安装”；
2. 在 PS 图层面板点**一个**文字图层，确认日志有“收到 PS 回调”；
3. 确认“分发宿主事件 name=selection”；
4. 确认“文字属性已更新 family/size/weight”；
5. 再点另一个文字图层，重复 2-4；
6. 多选两个图层，确认不刷新（原版行为）。
