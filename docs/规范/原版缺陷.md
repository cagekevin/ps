# 原版的缺陷（不要照抄）

> 原版**不是标准答案**。它的视觉可以照搬，但工程做法有大量问题。
> 下面每条都带实测数据，来源是 `app.bf68b505.css`、`56d7.js`、`icons-sprite` 抽取结果。
>
> 判断原则：**视觉照原版，工程照我们自己的规范。**

---

## 一、资源与产物

| 缺陷 | 实测 | 我们的做法 |
|---|---|---|
| **测试资源打进生产包** | 图标 sprite 共 **241** 个 symbol，其中 **52 个** 是 `fol-icon-test*`（占 21%） | 抽取时过滤，只保留 189 个真实图标 |
| CSS 体积失控 | `app.css` **194 KB**，`var(--)` 出现 **0 次** | token 化，改一个色只改 `tokens.css` 一行 |
| 字体图标从未加载 | `.gdaicon-*` 类有 24 个，但 `@font-face` **0 次**，扩展目录里也没有 woff/ttf → 这些图标在原版里就是空白 | 只用 SVG sprite，不引入字体图标 |

## 二、代码卫生

| 缺陷 | 实测 | 我们的做法 |
|---|---|---|
| **`console.log` 残留** | **40 处** | 统一走 `utils/logger.ts`，`npm run check` 会拦 |
| **原生 `alert()`** | **14 处** | 统一 `feedback`（toast / modal） |
| **`!important`** | **64 处** | 禁止，`npm run check` 会拦 |
| 选择器重复定义 | `body` `#app` `a` `img` `textarea` 等 **18 个**选择器被定义多次 | 每个组件 scoped，全局只有 `tokens` + `global` + `layout` |

## 三、状态与命名

| 缺陷 | 实测 | 我们的做法 |
|---|---|---|
| **没有禁用态样式** | `:disabled` 出现 **0 次** | 统一 `opacity: .45` + `cursor: default`，写在 `global.css` 约定里 |
| **命名不统一** | `.is-active` **0 次**，用 `--active` 修饰符；同一类名多处重复 | `g-`（组件）/ 页面名 / `u-`（utility）三前缀 + `.is-*` 状态 |
| 字符串魔法值 | `"ok"` 出现 **12 次**，靠字符串判断返回状态 | `CepError` 六种 code + 类型化返回 |
| 兼容两套返回结构 | `ztgl_initSystemList` 同时支持 `"ok"` 和数组，说明接口改过但没清理 | 两种都处理，但**记进 `docs/架构/jsx契约.md`**，标明哪个是历史包袱 |

## 四、数值无规则

| 维度 | 原版实际分布 | 我们的做法 |
|---|---|---|
| 间距 | 5px×37、10px×37、4px×34、15px×24、6px×21、8px×18 | `--sp-1..7` 阶梯 + 3 个 `--sp-exact-*` |
| 圆角 | 4px×111、5px×65、2px×14、3px×5、6px×4 | `--r-xs/sm/md`（缺 5px，见台账） |
| 控件高度 | 24×40、30×38、20×25、28×23、26×21、12×16 | `--h-*`（缺 30/28，见台账） |
| 字号 | 25 种取值（9~100），12px 用了 129 次 | `--fs-*` 8 档 |

**结论**：原版是"每处手调"，我们是"先定阶梯再套用"。代价是与原版有 1~2px 差异，收益是后续 6 个页面不用重新决策。

## 五、我们**故意保留**的原版行为

这些看着像缺陷，但其实是正确设计，别改：

| 行为 | 为什么保留 |
|---|---|
| 图标默认 `1em` | 跟随字号是合理设计，比固定 px 好 |
| 列表项 hover 背景变亮 `#424242` | 比加边框更轻，适合密集列表 |
| 导航激活用 `#222` 凹陷 + 蓝色图标 | 凹陷比凸起更符合"当前所在"的语义 |
| 空态用矢量插画而非图标 | 插画比图标更有安抚感，且是原版既有资源 |

## 怎么防止再犯

| 缺陷类型 | 守卫 |
|---|---|
| 硬编码色值/字号/圆角/图标尺寸 | `npm run lint` |
| `!important` / `console.log` | `npm run lint`（同一条规则） |
| 资源带测试数据 | `10-逆向流水线/14-sprite.cjs` 抽取时过滤 |
| 数值无阶梯 | `docs/规范/视觉规范.md` + `tokens.css` |
| 接口返回结构靠猜 | `docs/架构/jsx契约.md` + 探针页 |
