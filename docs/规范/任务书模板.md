# 任务书模板（三段式）

> **格式没有机器闸了**（2026-10-25 删 `spec:check`：手写文档不作为门禁）。改格式时对着这份模板自己核：甲区目标+判据、乙区逐条回执、丙区到文末，三区之外不许有正文。

## 甲区【可执行】

1. **目标**：一句话说清"做完什么东西、怎么算达标"。判据能核对，不写"优化一下"。
2. **判据**：逐条可验（命令输出 / 行号 / 测试名 / 退出码），每条都能说"不满足时怎么发现"。
3. **不许碰**：列出不允许改的路径与行为；没写等于允许，所以必须写。
4. **交什么**：文件清单 + 提交标识。

## 乙区【参考·未验证，默认不采纳，你逐条标"采纳 / 驳回 + 依据"】

1. 主控的猜测、倾向、习惯——执行者必须逐条回执，不许默默照做。
2. 每条回执只能写 `采纳` 或 `驳回 + 依据`，不许写"可以考虑"。

**乙区规矩**：每一条都要一行回执。

## 丙区【问题】

1. 主控自己不确定的地方、要执行者反考的地方，写在这里。
2. 这一区不约束格式，也不要求回执。
