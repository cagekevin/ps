### 3.3 条目元信息格式（实测）

```json
{"name":"天猫头PNG","ext":"psd","width":502,"height":264,"size":"720.31","star":0,
 "id":"FIF75C4A47976C07DD","find":[],"time":"20191121092855","tags":[],"folder":[],
 "note":"","adjustY":0}
```

- `id` 同时是目录名（`<id>.info`）与文件名来源（`getFilePsdPath`：`path.psd + "/" + id + ".info/" + name + "." + ext`，`:66797`）。
- `folder` 是所属文件夹 id 数组；空数组的条目在缓存里进 `unfiled`，非空进 `all`（`:66213-66217`）。
- `adjustY` 在写回时重置为 0（`:66662`）。
- `star` 与右键菜单的 `Score` 联动（设置入口 `:26143-26152`、`setScore` `:27143`、写回 `:68592`）。

> **样本限制（UNVERIFIED）**：只有 **1 条** `info.json`（回收站里的 2019 年条目），所以上面这 12 个键是
> 「这 1 条里出现的字段」，**不等于完整 schema**——不能排除还有装库时才有、或老版本才有的可选键。
> 真机新建一条再读一次才能定案；在那之前，`TemplateItemInfo` 类型按「已知 12 键 + 允许额外键」写，不要写死。

### 3.4 有没有云端兜底

**没有。** 三重证据：
