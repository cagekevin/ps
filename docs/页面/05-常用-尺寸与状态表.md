## 2. 官方"同一件不同值"的三处（按规矩分别列，不取平均）
1. 功能格方块：全局 50×50 / 本页 32×32（位置 110327 vs spec `:35671`）→ 本页按 32×32。
2. 分隔线：全局 `.line` 100%宽 1px高 #222（位置 6334）/ 本页 scoped 改成 `calc(100% - 30px)`、上下 5、色 rgba(0,0,0,.15)（spec `:35634`）→ 本页按后者。
3. 小图标按钮：通用 `.base-icon`（26×26 + 悬停半透明黑 + #444 边）/ 样式页底栏 `.bottom-hover`（只给高 100%、悬停纯 #222、无边框）→ 本页按前者（`PageBottomBar` 那套）。

## 3. 官方本来就不一致的（抄的时候别"统一"）
- 样式页底栏图标与动作/重命名页底栏图标本就不是一套（理由同上第 3 条）。→ 本页不涉及底栏，不改它们。

## 6. 收尾三问
1. **哪几格是猜的**：**没有**。凡是没查到官方值的格都写成"查不到"或"官方未规定"，没有自己填数；凡写"值需核"的（半宽/预设小按钮/`GCollapse`）都已标明未核。
2. **有没有整行定不下来**：有——**勾选框**与**单选项**两行定不下来，因为官方对应组件的样式根本不在我们能读到的 CSS/JS 里（§5-1、§5-2）。这两行只能按我方既有控件走，并把这决定记录在案（§4-1、§4-6）。
3. **最可能出现"同一页两样子"的是哪一行**：**输入框**。官方自己就分了三套（宽 80 / 一半减 5 / 宽 70 高 30，位置 111045、6140、108522），而本页 16 个输入框分属四种用途（倍数、变换参数、导出路径与品质、参考线宽度、分布间距）——只要有一处图省事写了裸宽度，就会和别处不一样。
