## 二、怎么用（重要）

1. **先查这里，再查 `docs/生成/`**。`docs/生成/` 是二手结论，可能过期；`app.v4.js` 是一手事实。
2. **大文件不要整读**。73,703 行用窗口读：
   `Get-Content docs/原版/01-原版源码/panel/js/app.v4.js | Select-Object -Skip <N-1> -First <M>`
3. **搜关键字不要用 `rg`**（本机没有）：用 `Select-String -Path <文件> -Pattern '<正则>'`，
   仓内文件用 `git grep -n`。
4. **jsx 名字有权威清单**：`app.v4.js:17058` 是一行 switch（jsx 名 → case 号），
   `17061-17184` 是 `l(名字, 成功文案, 通道, ...)` 的调用封装。**任何 `jsx` 函数名先在这里对一遍**，
   对不上就是假的。这条已经踩过：`cy_customTransform` 官方叫 `cy_customBuildTransform`；
   `cy_referenceLine` 官方没有；`cy_distribute` 官方叫 `cy_distributedByPitch`。
5. **改了 `docs/生成/页面规格/` 的来源，就能重跑生成**：`node docs/原版/tools/15-page-spec.cjs`
   （脚本里的相对路径按 `../reference` 写死，跑之前先确认或就地改路径）。
