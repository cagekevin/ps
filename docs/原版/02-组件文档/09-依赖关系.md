## 依赖类型说明

| 类型 | 含义 | 重写时怎么办 |
|---|---|---|
| `$emit` | 向父组件抛事件 | 保留事件名，父组件要监听 |
| `$refs` | 直接操作子组件/元素 | 换成 ref 或 querySelector |
| `$parent` | 直接访问父组件 | 改成 props / provide / store |
| `$root` | 访问根实例 | 改成 store |
| `$store.state` | 读全局状态 | 换成 Pinia/Vuex |
| `$store.dispatch/commit` | 调 action/mutation | 换成 Pinia action |
| `components` | 子组件引用 | 照搬组件结构 |
| `$on` / `$bus` | 事件总线 | 换成 mitt 或 provide/inject |
