## 二、新机器重建（4 步）

**前提**：装好 Photoshop（CEP 11+，PS 2019 及以上）。

### 1. 放扩展壳

把 `01-官方资源\01-安装包\设计助理\设计助理安装包\Install\com.sf.设计助理2.7`
整个复制到：

```
%APPDATA%\Adobe\CEP\extensions\com.sf.设计助理2.7
```

达芬奇、智能参考同理，对应各自的 `Install` 目录。

### 2. 放面板 UI

把 `01-官方资源\04-CEP资源包\CEP001-设计助理` 里的所有内容复制到：

```
%APPDATA%\fz.FengZi1Hao
```

达芬奇 → `%APPDATA%\fz.FengZi2Hao`，智能参考 → `%APPDATA%\fz.FengZi5Hao`。

### 3. 放模板（可选）

```
01-官方资源\04-模板\pszhuli-TemplateCenter  →  %APPDATA%\pszhuli-TemplateCenter
01-官方资源\04-模板\PSDTemplate.pszhuli     →  %APPDATA%\PSDTemplate.pszhuli
```

### 4. 打开 Photoshop

「窗口 → 扩展功能 → 稿定-PS设计助理」。

首次会加载远程登录页（因为 `%APPDATA%\SheJiZhuLi\user.ini` 不存在）。

## 三、如果报「未经正确签署」

说明你替换过扩展里的文件。开一下 CEP 调试模式：

```
reg add "HKCU\Software\Adobe\CSXS.12" /v PlayerDebugMode /t REG_SZ /d 1 /f
reg add "HKCU\Software\Adobe\CSXS.11" /v PlayerDebugMode /t REG_SZ /d 1 /f
```

然后完全退出 Photoshop 再打开。想恢复严格校验就删掉这两个值。

## 四、调试流程（重点）

改动前**先存一版**：

```
node D:\稿定设计助理-存档\工具\版本.js save "改了扩展入口"
```

然后改文件、重启 PS 验证。改坏了：

```
node D:\稿定设计助理-存档\工具\版本.js list       → 看有哪几版
node D:\稿定设计助理-存档\工具\版本.js restore 3  → 退回第 3 版
```

`restore` 会自动先把当前状态存一版（叫「还原前自动备份」），所以退错了还能再退回来。

**只管 3 个文件**，每次约 1.6MB：

| 文件 | 路径 |
|---|---|
| 扩展入口 | `%APPDATA%\Adobe\CEP\extensions\com.sf.设计助理2.7\index.html` |
| 面板入口 | `%APPDATA%\fz.FengZi1Hao\index.html` |
| 面板逻辑 | `%APPDATA%\fz.FengZi1Hao\js\app.*.js` |

## 五、关键事实（改之前先看）

**1. 面板会自我覆盖**

PS 启动后约 20 秒，面板会从远程拉资源并覆盖 `%APPDATA%\fz.FengZi1Hao` 整个目录。
所以**直接改面板文件是不可持续的**，改动会被冲掉。要持久化只能从「扩展入口」接管。

**2. 登录链路**

```
扩展 index.html → 读 SheJiZhuLi\user.ini
  ├─ 存在 → 读 info.ini → 加载 %APPDATA% + 路径（通常是 /fz.FengZi1Hao/index.html）
  └─ 不存在 → iframe 加载 https://cepapp.pszhuli.com/index/CEP001
```

**3. 资源包格式**

```
base64( gzip( JSON{ folder:[], file:[{name, data}] } ) )
```

下载地址由 `GET https://zhuli.gaoding.com/api/device/active/file?type=CEP001` 下发，需要登录态。

**4. 不可逆的缺口**

- CEP003「下载图标」官方已下架，无法获取
- `%APPDATA%\SheJiZhuLi` 已删除且无备份，只能靠登录后云端同步恢复一部分
