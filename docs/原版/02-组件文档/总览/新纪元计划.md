# 新纪元计划 · 面板重写

> 起点：逆向完成，BUILD-SPEC 707 文件
> 终点：一个可长期维护的自建面板
> 制定时间：2026-10-20

---

## 一、为什么重写

| 原面板的问题 | 后果 |
|---|---|
| Vue 2 已 EOL（2023-12-31） | 无安全更新，生态停滞 |
| 所有组件塞在 1.5MB 的 `56d7.js` | 改一个组件要重编译全部，无法按需加载 |
| 无 TypeScript | 重构无类型保护，改错要跑起来才知道 |
| 全局 CSS 198KB，无作用域 | 样式冲突靠命名约定 |
| 热更新每 20 秒检查一次 | 覆盖我们的改动，纯负担 |
| 组件是 `Object(Y.a)(...)` 编译产物 | 无法单独复用 |

**结论：改它不如重写。**

---

## 二、重写范围

| 层 | 做什么 | 不做什么 |
|---|---|---|
| **UI** | 全部重写（Vue 3 + TS） | — |
| **数据层** | 重写（api/） | — |
| **状态** | 重写（Pinia） | — |
| **PS 能力** | **继续调用原厂 jsxbin** | ❌ 不逆向、不重写 |
| **批量套版** | 暂不做（用户明确不要） | — |
| **云端内容** | 不做（模板/素材/专题） | — |

**一句话：重写壳和数据流，PS 操作继续用原厂黑盒。**

---

## 三、架构

```
src/
├─ cep/                  ★ 唯一与 PS 通信的地方
│   ├─ eval-script.ts    evalScript → Promise（超时/重试/错误码）
│   ├─ fs.ts             文件读写
│   ├─ ps.ts             领域封装（字体/图层/导出）
│   ├─ host.ts           宿主信息
│   └─ types.ts          PS 接口类型
│
├─ api/                  ★ 唯一发网络请求的地方
│   ├─ client.ts         HTTP 封装
│   └─ types.ts
│
├─ stores/               ★ Pinia
│   ├─ app.ts            用户/设置/窗口
│   ├─ font.ts           字体列表/收藏
│   └─ ...
│
├─ router/index.ts       路由表
├─ layouts/              导航 + 内容区
├─ pages/                一页一文件夹
│   ├─ font/
│   │   ├─ index.vue
│   │   ├─ components/
│   │   └─ composables/
│   └─ ...
├─ components/           通用组件
├─ composables/          跨页面复用
├─ styles/               变量 / mixins / 全局
└─ utils/                纯函数
```

### 四条铁律

1. **CEP 层是唯一 PS 出口**——所有 `evalScript` 经过 `cep/ps.ts`，有类型、有超时
2. **api 层是唯一网络出口**——想切本地数据源，只改这一层
3. **pages 一页一文件夹**——删页面 = 删文件夹
4. **类型驱动**——先写 `types.ts`，再写实现

## 五、工作流（每个页面）

```
1. 读 02-组件/<组件>.md          → 知道有哪些方法、data
2. 读 08-模板/tpl_<组件>.md      → 知道界面结构
3. 读 02-组件/methods/<组件>.md  → 知道方法实现
4. 读 09-依赖关系.md             → 知道依赖什么
5. 写 types.ts                  → 定义数据结构
6. 写 cep/ps.ts 的函数           → 封装 PS 调用
7. 写页面组件                    → 按模板结构
8. 调 jsx 验证                   → 实际跑
9. 对照原版调细节                → 间距、交互
```

**每步都有对应的 BUILD-SPEC 文档，不用猜。**

## 六、已知风险

| 风险 | 影响 | 应对 |
|---|---|---|
| **CEF 兼容** | Vue 3 依赖 Proxy | P1 第一件事就是验证；不行就退 Vue 2.7 |
| **动态绑定** | `v-if`/`v-for` 没自动提取 | 看 render 源码人工还原 |
| **全局模块引用** | `V.a.info`、`n("1bab")` 要替换 | 每个组件 2~3 处，手工处理 |
| **140 个子组件未解析** | 缺组件 | 遇到时看源码补 |
| **jsx 参数未知** | 部分函数不知道怎么调 | 靠实测，记录到契约表 |
| **样式还原** | 全局 CSS 无作用域 | 复用原 CSS，逐步迁移到 scoped |
