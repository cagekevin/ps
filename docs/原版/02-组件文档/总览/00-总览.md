## 五、怎么改功能

### 改代码

```
1. 编辑 %APPDATA%\Adobe\CEP\extensions\com.local.psz.panel.v4\panel\js\app.v4.js
2. 保存
3. 关掉面板重新打开（不用重启 PS）
4. 生效
```

**不用编译**——`app.v4.js` 本身就是成品 bundle。

### 定位代码

```bash
# 搜文案（最快）
grep "批量套版" app.v4.js

# 搜样式类
grep "overprint-" app.v4.js
```

或者查 `03-源码还原\文案索引.md`（文案 → 模块）。

### 改坏了怎么恢复

```
从 01-稳定版\V4-可编辑源码版\panel\js\app.v4.js 复制一份覆盖回来
```

### 回退到旧版本

```bash
node "D:\稿定设计助理-存档\07-工具\版本.js" list
node "D:\稿定设计助理-存档\07-工具\版本.js" restore 3
```

## 六、已知限制

| 限制 | 说明 |
|---|---|
| ~~jsxbin 不可读~~ | **已可解密**：AES-128-CBC + gzip → 330KB `@JSXBIN@`，可独立 `evalFile` 加载（详见 `jsxbin解密方法.md`） |
| 变量名是压缩的 | `t/e/n/a/s`，靠 class 和文案定位 |
| 模板/素材依赖云端 | 服务器关了会空白，无法离线复刻 |
| 云同步在对方服务器 | 想自建需另写 HTTP 服务 |
| 启动慢 6 秒 | `ztgl_initSystemList` 返回数组而非 `"ok"`，触发 4 次重试（可改） |
