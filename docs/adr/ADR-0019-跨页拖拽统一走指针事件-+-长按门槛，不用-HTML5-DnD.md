# ADR-0019 · 跨页拖拽统一走指针事件 + 长按门槛，不用 HTML5 DnD

- **状态**：生效
- **结论**：跨页拖拽统一走指针事件 + 300ms 长按门槛，废弃 HTML5 DnD；落点计算与落点形状都收口在 domain/reorder。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：动作页用 HTML5 DnD 是未经权衡直接实现，错误被复制两次

## 背景

动作页最初用 HTML5 DnD 是**没有经过方案权衡就直接实现的**；重命名页按「复用第一页已有实现」照抄，错误被复制了两次；直到样式页才按原版的做法复刻出正确机制。

选指针事件的理由是能力对比，不是「原版这么做」：拖影是浏览器截的静态图改不了；原生拖放在开始拖动时立刻触发，做不出长按门槛；落点只给目标元素，插前/插后要靠样式猜；指针事件可以自己控时机、自己算落点。

## 判据

1. **跨页排序拖拽统一走指针/鼠标事件 + 300ms 长按门槛**。
2. **实现收口**在 `src/composables/useLongPressDrag.ts`；**落点计算与落点形状**都收口在 `src/domain/reorder.ts`（落点形状全仓一份，不许内联手写）。
3. **HTML5 DnD 全部废弃**；两套机制**不许在同一页混用**。
4. 数值滑块一类非排序交互不算拖拽排序，另按各自交互处理。

**唯一入口**：`src/composables/useLongPressDrag.ts`（拖拽实现）、`src/domain/reorder.ts`（落点计算与落点形状）。

**禁止清单**

| 禁止 | 为什么 |
|---|---|
| 出现原生拖放属性与事件 | 机制已废弃，且拖影与门槛不可控 |
| 同一页同时用指针拖拽与原生拖放 | 两套语义并存，行为不可预测 |
| 各页自写第二套指针拖拽 | 门槛、落点、清理各写一遍 |
| 落点形状在别处内联手写 | 同一形状多份，改一处就漂 |

**代价**：指针事件要自己处理滚动容器自动滚动与边界处理。

**什么时候推翻**：出现需要原生手势语义的场景，或宿主升级到支持完整指针捕获时再复核。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果

- 📌 **违反时的判据**：页面里出现原生拖放属性与事件；或同一页同时出现指针拖拽与原生拖放。
