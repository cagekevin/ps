# ADR-0011 · CSS 全部内联进 JS，不产出独立 css 文件

- **状态**：生效
- **结论**：CSS 全部内联进 JS，不产出独立 css 文件：少一次请求就少一个失败点，也避免相对路径问题。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：file:// 下 CSS 404 会导致裸 HTML

## 背景

宿主走 file:// 协议，少一次请求就少一个失败点 —— 样式表 404 会直接导致裸 HTML；也避免相对路径问题。

## 判据

1. **产物只有一个脚本文件**：样式由构建工具注入，不产出独立的样式文件。
2. **不为「改样式不重新构建」引入独立样式表**。

**唯一入口**：构建配置 `vite.config.ts`（产物形态与样式注入）。

**禁止清单**

| 禁止 | 为什么 |
|---|---|
| 产物里出现独立的样式文件 | 多一次请求就多一个失败点（404 → 裸 HTML） |
| 引入独立样式表以支持热替换 | 相对路径问题会回来，且那时连脚本都要拆 |

**代价**：无法单独替换样式表；sourcemap 变大；单文件体积大。

**什么时候推翻**：需要「改样式不重新构建」的热替换能力时（那时连脚本都要拆）。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果

- 📌 **违反时的判据**：产物里出现独立的样式文件。
