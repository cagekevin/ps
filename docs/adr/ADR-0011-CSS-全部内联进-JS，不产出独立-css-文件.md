# ADR-0011 · CSS 全部内联进 JS，不产出独立 css 文件

- **状态**：生效
- **结论**：CSS 全部内联进 JS，不产出独立 css 文件：少一次请求就少一个失败点，也避免相对路径问题。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：file:// 下 CSS 404 会导致裸 HTML

## 背景

源文档（`docs/架构/决策记录.md`）本条未单列「背景」段：旧约定与原因写在「决定 / 原因 / 由来」字段里，已随「判据」段逐字搬来。

## 判据（它凭什么成立 / 为什么不成立）

- **决定**：产物只有 `index.js`（CSS 由 Vite 注入 `<style>`），没有 `assets/*.css`。
- **原因**：CEP 走 `file://`，少一次请求就少一个失败点（CSS 404 会导致裸 HTML）；也避免相对路径问题。
- **代价**：无法单独替换样式表；sourcemap 变大；单文件 638KB。
- **什么时候推翻**：需要“改样式不重新构建”的热替换能力时（那时连 JS 都要拆）。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果


- 📌 **违反时的判据**：`dist/` 里出现 `assets/*.css`；或有人为「改样式不重新构建」引入独立样式表。
