# ADR-0013 · 视觉规范：三处故意不照抄原版

- **状态**：生效
- **结论**：视觉规范三处故意不照抄原版：间距用 flex 间隔、阶梯只有 4/6/8、图标着色跟随文字色。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：原版 CSS 的 gap 出现 0 次、5px/10px 不在 8px 栅格

## 背景

原版样式全部用右边距做间距 —— 那是 2019 年的浏览器限制，宿主已是 Chromium 99，flex 间距完全可用，而且不会在最后一个元素留空白。5 与 10 不在 8 栅格里，混用会让间距失去节奏。预设色类只能覆盖固定场景；跟着文字色走更省一类样式，hover 自动变。

## 判据

1. **间距用 flex 的 gap**，不用原版的右边距。
2. **间距阶梯只有 4 / 6 / 8**，不保留原版的 5 与 10。
3. **图标着色用 currentColor**，不引入原版的预设色类。

**唯一入口**：详细规范 = `docs/规范/视觉规范.md`（本条是判据面，那张表是执行面）。

**禁止清单**

| 禁止 | 为什么 |
|---|---|
| 用右边距做间距 | 最后一个元素会留空白；且与阶梯口径冲突 |
| 出现 5 / 10 的间距值 | 不在 8 栅格里，间距失去节奏 |
| 用预设色类给图标着色 | 只能覆盖固定场景；跟着文字色走更省 |

**代价**：与原版像素级不完全一致（个别地方差 1~2px）。

**什么时候推翻**：要求像素级还原原版时，可以逐处改用右边距，但不要全局改回去。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果

- 📌 **违反时的判据**：新组件里用右边距做间距；出现 5 / 10 的间距值；用预设色类给图标着色。
