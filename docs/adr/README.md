# docs/adr —— 架构决策记录（ADR）

> **一条 ADR 一个文件**：`docs/adr/ADR-NNNN-<标题>.md`（NNNN 四位编号）。
> **本 README 的索引表是产物**：由 `node scripts/adr.mjs index --write` 生成，**禁手改**（改了会被下次生成覆盖）。
> 真源 = 各 ADR 文件的**头部字段**（`状态` / `结论` / `日期` / `裁定人` / `触发` / `取代` / `被取代于` / `毕业去向`）。

## 唯一入口：`scripts/adr.mjs`

```powershell
node scripts/adr.mjs list [--all] [--json]     # 默认只列现行；--all 含已退出
node scripts/adr.mjs show <NNNN|文件名片段>     # 单条全文
node scripts/adr.mjs search <关键词> [--json]   # 标题/结论/触发/正文全文匹配（多词 AND，含已退出）
node scripts/adr.mjs index [--write]           # 索引生成（幂等；--write 强制重写）
node scripts/adr.mjs audit [--json]            # 只读体检（不是闸）
node scripts/adr.mjs stats                      # 状态分布
node scripts/adr.mjs add / status / rm          # 写入口（详见脚本头部注释）
node scripts/adr.mjs refs <NNNN|--check>        # 引用面 / 断链
node scripts/adr.mjs doctor                     # Step 1 体检编排（只读）
```

**任何改动都必须经过它**：手改文件后索引会漂移，而索引是读者唯一入口（`debt.mjs` 同款定位）。

## 硬约束（`scripts/adr.mjs` 源码即判据）

| 项 | 值 |
| --- | --- |
| 文件命名 | `ADR-<NNNN>-<标题>.md`，四位编号，与首行标题一致 |
| 首行 | `# ADR-NNNN · 标题` |
| 必填字段 | `状态` / `日期` / `裁定人` / `结论`（缺一个即报错） |
| 状态枚举 | `草案` / `生效` / `已取代` / `已弃用` / `已否决` / `已毕业`（白名单，无第六态） |
| 正文上限 | 整个文件 **80 行**（口径 = 文件总行数，含标题与头部字段行） |
| 必填段落 | `## 背景` / `## 判据` / `## 决议` / `## 后果` |
| 结论长度 | ≤ 120 字，**不许含裸竖线 `|`**（会撑破索引表格） |

## 退出机制（ADR 不是只进不出的档案）

| 状态 | 什么情况 | 怎么处理 |
| --- | --- | --- |
| `已取代` | 有新决定覆盖了它 | `status <NNNN> --to 已取代 --by <NNNN>`（双向连线，取代轮必须写 `## Lessons Learned`） |
| `已弃用` | 不再相关，**没有**取代者 | `status <NNNN> --to 已弃用`（写了「被取代于」会报错） |
| `已否决` | 考虑过但没采纳（留档，防后人再提一遍） | `status <NNNN> --to 已否决` |
| `已毕业` | 判据升为可自动检查的载体（fitness function） | `status <NNNN> --to 已毕业 --note "<载体:文件:行>"` |

**正文不因「过时」而删，只加状态行。** 删掉等于丢掉「当时为什么这么想」。

## 新增 ADR

```powershell
node scripts/adr.mjs add --title "…" --conclusion "…" --user-approved
```

- `--user-approved` **真落盘时必填**（缺 ⇒ 拒绝落盘 exit 2）；六问的答卷人是 AI，但**决策人是用户**。
- 取号 = 高水位线（现存 ∪ 已删号）—— 编号一旦出现永不复用。
- 新条目是**空壳**（四段占位符）：`audit` 会报「模板占位符残留」，写成真内容才算落盘。
