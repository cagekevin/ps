# ADR-0004 · 构建产物直接输出到 CEP 扩展目录

- **状态**：生效
- **结论**：构建产物直接输出到 CEP 扩展目录，build 即部署；lib/all.decrypted.js 必须来自 public/。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：省掉「构建 → 复制 → 忘复制某个文件」这类问题

## 背景

源文档（`docs/架构/决策记录.md`）本条未单列「背景」段：旧约定与原因写在「决定 / 原因 / 由来」字段里，已随「判据」段逐字搬来。

## 判据（它凭什么成立 / 为什么不成立）

- **决定**：`outDir = %APPDATA%\Adobe\CEP\extensions\com.local.psz.panel.v5`，`public/` 放 manifest 和 lib。
- **原因**：省掉"构建 → 复制 → 忘复制某个文件"这类问题。`build` 即部署。
- **代价**：`emptyOutDir` 会清空目录，所以 `lib/all.decrypted.js` 必须来自 `public/`，不能手动放。
- **什么时候推翻**：需要同时维护多个扩展版本时（比如做灰度）。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果


- 📌 **违反时的判据**：`outDir` 指向仓库内目录而 `build` 之外还需手工复制文件；或 `lib/all.decrypted.js` 被手动放进 `outDir` 而不是来自 `public/`。
源文档本条未单列「后果」段；推翻条件已逐字保留在「判据」段的「什么时候推翻」字段。
