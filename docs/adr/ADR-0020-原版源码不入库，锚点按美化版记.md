- **状态**：已取代
- **结论**：（已被 ADR-0025 取代）原版源码不入库、锚点按美化版记并按字符串定位：源码入库后该前提已消失。

- **裁定人**：UNVERIFIED（源文档未记每条裁定人）

## 判据（它凭什么成立 / 为什么不成立）

> ⚠️ **已被 ADR-25 取代（2026-10-23）**：源码已于 2026-10-23 入库（`docs/原版/`，commit `36472b3`，1472 文件），"不入库"的前提没了；"检索用字符串定位、不按行号"也随之作废——**行号现在就是可当场复核的锚点**。本条正文保留，因为它记录了"为什么当初只能靠字符串定位"（压缩版可读、美化版不入库）。仍成立的部分：别的插件安装副本不得据以核对（版本不一致）。

- **决定**：
  - 原版还原源码**不入库**（压缩版 1.5 MB、美化版约 7 万行，且涉及版权）。
  - **那份安装副本不可用于核对**：`~/Library/Application Support/fz.FengZi1Hao/js/app.8565afb8.js` 是 2022-09 的安装版本，与文档调查所用版本不一致（文档引用的 `56d7.js` / `0425.js` 在该副本中不存在），**不得据它下任何结论**。需要复核时须另取与文档同版本的源码。
  - `docs/` 里的 `app.v4.js:行号` 锚点**按美化版记**；检索时用字符串定位，**不按行号**。
  - 使用规则见 `AGENTS.md` 第 19 条：二手证据可直接据以开工，锚点是将来复核的入口，不是当下必须重跑一遍。
- **原因**：不入库是因为体积与版权。该副本版本不可信，因此复核只能依赖锚点，以及将来取得的与文档同版本的源码；字符串（class 名、jsx 函数名、stringID、提示文案、文件后缀）在压缩版里原样保留，是定位手段，但不能替代版本确认。
- **代价**：
  - 行号锚点在压缩版上失效，只能当"美化版的坐标"用；
  - 压缩版函数名被 mangle，函数级定位要靠调用处的字符串；
  - 文档里的行号一旦美化设置变了就会漂移。
- **复核方法**：
  - 前置条件：先取得**与文档调查同版本**的压缩源码；2022 安装版不可用（见上）。
  - 用字符串定位，取命中点前后 400 字符上下文：

    ```python
    import re
    from pathlib import Path

    SRC = Path('<与文档同版本的压缩源码路径>')
    text = SRC.read_text(encoding='utf-8', errors='replace')
    key = 'ys_getFontInfo'  # 换成要查的 class 名 / jsx 函数名 / stringID / 提示文案 / 后缀
    for m in re.finditer(re.escape(key), text):
        start, end = max(0, m.start() - 400), min(len(text), m.end() + 400)
        print(f'--- offset {m.start()} ---')
        print(text[start:end])
    ```

  - 结论标注格式：`已核（<源文件名>，字符串定位：<关键字>）`，**不写行号**。
- **什么时候推翻**：拿到可入库的授权副本时；或取得与文档同版本的源码并把锚点重挂到它上面时。
