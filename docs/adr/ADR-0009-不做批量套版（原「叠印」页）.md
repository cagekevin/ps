# ADR-0009 · 不做批量套版（原「叠印」页）

- **状态**：生效
- **结论**：不做批量套版（原「叠印」页）：/overprint 路由与导航入口删除，需求方明确不做。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：Overprint.js 实为「变量设置 + 批量套版」，与印刷叠印无关

## 背景

源文档（`docs/架构/决策记录.md`）本条未单列「背景」段：旧约定与原因写在「决定 / 原因 / 由来」字段里，已随「判据」段逐字搬来。

## 判据（它凭什么成立 / 为什么不成立）

- **决定**：`/overprint` 路由和导航入口都删掉。
- **原因**：`Overprint.js` 实际是「变量设置 + 批量套版」（`switchdata: ["变量设置","批量套版"]`），跟印刷叠印无关；需求方明确不做。
- **代价**：如果以后要做，需要重新接 Excel 解析 + 批量导出 + PSD XMP 读写。
- **什么时候推翻**：需求方明确要。
