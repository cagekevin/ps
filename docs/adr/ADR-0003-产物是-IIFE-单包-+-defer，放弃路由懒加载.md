# ADR-0003 · 产物是 IIFE 单包 + defer，放弃路由懒加载

- **状态**：生效
- **结论**：产物是 IIFE 单包 + defer，放弃路由懒加载：file:// 下源标识为空，按需加载不可靠。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：CEP 走 file://，模块脚本被 CORS 拦

## 背景

宿主走 file:// 协议，模块脚本被 CORS 拦（源标识为空），按需加载在 file:// 下不可靠。

## 判据

1. **产物是单包**：构建输出为 IIFE 格式，且动态导入全部内联（不留独立 chunk）。
2. **HTML 里的脚本必须带 defer**：脚本在 head 里，去掉模块类型后会变成阻塞脚本，在 body 之前执行，容器还不存在 → 面板全黑。**defer 不能去掉。**
3. 打包体积超过 **2MB** 或冷启动明显变慢时，再考虑本地 http 服务 + 真分包。

**唯一入口**：`vite.config.ts`（产物格式与 defer 注入）。

**禁止清单**

| 禁止 | 为什么 |
|---|---|
| 把产物改回 ESM / 留独立 chunk | file:// 下按需加载不可靠 |
| 去掉 defer | 阻塞脚本先于容器执行，面板全黑 |

**代价**：所有页面打进一个包，「改一个组件要重编译全部」—— 这正是我们想摆脱的原面板问题。

## CEP 12 环境能力边界（踩过的，别再试）

| 能力 | 状态 | 说明 |
|---|---|---|
| `localStorage` | ✅ | 按扩展隔离，可用 |
| `ResizeObserver` / `IntersectionObserver` | ✅ | 宽度响应、滚动加载都靠它 |
| CSS 变量 / `:focus-visible` / `@layer` | ✅ | Chromium 99 全支持 |
| Node（`--enable-nodejs`） | ✅ | 需配 `--mixed-context` |
| `@container` 容器查询 | ❌ | Chromium 105+，CEP 12 是 99 → 宽度响应只能用元素宽度监听 |
| ESM / 动态导入 | ❌ | file:// 下源标识为空，被 CORS 拦 |
| 外部 `<use>` 引用 | ❌ | 同源限制，必须把 sprite 注入文档 |
| 用 fetch 读本地文件 | ❌ | 同源策略，读文件走 cep 的读原语 |
| `structuredClone` | ✅ | Chromium 98+ |
