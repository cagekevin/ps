## 判据（它凭什么成立 / 为什么不成立）

> ⚠️ **已过期（2026-10-23）**：本条描述的代码已不存在。mock 统一到 `src/cep/jsx/mock.ts`（该文件自述「替代了什么：旧初始化门面里的双路径」），初始化门面只剩初始化边界一处判断，对应债条已结。**正文保留**，因为它记录了当初为什么允许双路径。

- **决定**：初始化门面里每个函数都先判宿主是否可用，不可用就返回 mock。
- **原因**：最快让 90% 的 UI 开发脱离 PS。
- **代价**：违反 DRY，新增函数容易漏 mock，漏了浏览器里直接崩。
- **什么时候推翻**：第 3 个页面之前，改成适配器接口 + 两个实现，或者在注册表里加「每个导出函数必须有 mock 对应」的校验。
