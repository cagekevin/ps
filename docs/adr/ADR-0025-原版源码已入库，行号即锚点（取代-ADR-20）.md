# ADR-0025 · 原版源码已入库，可当场核对（取代 ADR-20）

- **状态**：生效
- **结论**：原版源码已入库随仓库分发，可当场核对；docs/原版/ 只读，jsxbin 仍不可读，安装副本仍不得据以核对。
- **日期**：2026-10-23（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：docs/原版/README.md 书面记录「源码已入库」
- **取代**：ADR-0020

## 背景

过去源码不入库，任何「官方是怎么做的」结论都无法在仓库内被当场复核，只能靠"检索用字符串定位"。源码入库后这个前提消失了。

## 判据

1. **原版源码入库随仓库分发**：`docs/原版/` 下含原版面板源码、样式表、组件文档、原版安装包与辅助工具。
2. **引用原版必须给可复核的坐标**（在 `docs/` 的文档里给行号；ADR 正文本身不写行号 —— 见 ADR 守护者的硬约束）。
3. **`docs/原版/` 只读**：不许改里面的任何内容（格式化、修 typo、重命名都不行）；要修正结论，改 `docs/页面/`、`docs/架构/`、`docs/生成/`。
4. **仍然不可读的只有原厂脚本包**：那部分继续按函数名查 `docs/架构/jsx契约.md`，**不许声称读过实现**。
5. **别的插件安装副本仍不得据以核对** —— 版本与调查不一致。

**唯一入口**：`docs/原版/`（只读证据区）、`docs/架构/jsx契约.md`（不可读部分的唯一查法）。

**禁止清单**

| 禁止 | 为什么 |
|---|---|
| 引用原版却不给可复核坐标 | 坐标编不出来就等于没核实 |
| 改 `docs/原版/` 里的任何内容 | 一手证据只读，改了就没法复核 |
| 对原厂脚本包声称读过实现 | 它仍不可读 |
| 拿别的插件安装副本下结论 | 版本与调查不一致 |

**与既有 ADR 的关系**：取代 ADR-0020（其正文保留，首行加状态行）；与 ADR-0001 无关（那条说的是原厂脚本包不逆向，本条说的是面板源码入库），别混。

**什么时候推翻**：入库源码与 `docs/` 现有调查结论不再是同一版本时（换版本要整目录替换并在 `docs/原版/README.md` 记一行日期与来源），或版权要求撤下时。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果

- 📌 **违反时的判据**：引用原版却不给可复核坐标；或有人改 `docs/原版/` 里的内容。

## Lessons Learned

- **ADR-20 当初的取舍是对的**：不入库确实换来了仓库体积与版权的安全，且「字符串定位」在只有压缩版的年代是唯一可用的复核手段 —— 它不是偷懒，是当时的最优解。
- **被高估的是「权宜」的寿命**：把「暂不」写成「决定」，让这条权宜状态存在了整整一天就开始反噬 —— 前提一旦消失，权宜必须当天退役，不能等「哪天想起来」。
- **可复用的判据**：一条 ADR 的「什么时候推翻」要写成**可观测事件**（「源码已入库」），而不是「拿到授权时」这种没有信号的措辞 —— 后者永远不会触发，ADR 就会永远有效地说谎。
