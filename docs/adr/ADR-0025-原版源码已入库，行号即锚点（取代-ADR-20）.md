## 判据（它凭什么成立 / 为什么不成立）

- **决定**：
  - 原版源码**入库随仓库分发**：`docs/原版/01-原版源码/panel/js/app.v4.js`（73,703 行美化版）、`panel/css/app.bf68b505.css`、`docs/原版/02-组件文档/`、`docs/原版/03-原版安装包/`、`docs/原版/tools/`，共 **1472 个文件**（commit `36472b3`）。
  - **锚点就是行号**：`app.v4.js:NNNN` 是可当场复核的坐标，用 `Get-Content <文件> | Select-Object -Skip <N-1> -First <M>` 或 `Select-String` 复核。**不再要求"检索用字符串定位、不按行号"**。
  - **`docs/原版/` 只读**：不许改里面的任何内容（格式化、修 typo、重命名都不行）；要修正结论，改 `docs/页面/`、`docs/架构/`、`docs/生成/`。
  - 仍然不可读的只有 `public/lib/all.decrypted.js`（原厂 jsxbin）：那部分继续按 jsx 函数名查 `docs/架构/jsx契约.md`，不许声称读过实现。
  - 别的插件安装副本（`~/Library/Application Support/fz.FengZi1Hao/js/`）**仍不得据以核对**——版本与调查不一致，这条从 ADR-20 原样保留。
- **由来（实证）**：
  - `docs/原版/README.md:9-13`：写明"2026-10-23 从仓库目录外搬进本仓库，唯一目的：任何'官方是怎么做的'的结论都能在本仓库内被当场复核"；`:19` 记 `01-原版源码/` 39 文件 / 6.8 MB，`:23` 记 `03-原版安装包/` 194 文件 / 9.5 MB。
  - `docs/原版/README.md:37-42`（§三"这改变了什么"）：过去源码不入库 → 现在"凡'官方怎么调 / 什么参数 / 什么结构'都必须回源码核对，不许再猜"，`UNVERIFIED` 只留给真机行为。**这就是 ADR-20 的推翻条件已经成立的书面记录**。
  - `docs/原版/README.md:26-27`：大文件按行窗口读（`-Skip <N-1> -First <M>`）——行号已是工作方式，不是"将来才有的坐标"。
  - 实测：`git log --oneline -1 36472b3` = `chore(evidence): 原版一手证据入库 docs/原版/…`；`(Get-ChildItem docs/原版 -Recurse -File).Count` = 1472。
- **什么算违规**：

  | 写法 | 判定 | 为什么 |
  |---|---|---|
  | 引用原版却不给 `文件:行号` | 违规 | 锚点编不出来就等于没核实（硬规则 19） |
  | 按"字符串定位、不写行号"给锚点 | 已过时 | 源码在手，行号可复核；字符串定位是 ADR-20 的权宜 |
  | 拿 `~/Library/.../fz.FengZi1Hao/js/` 那份副本下结论 | 违规 | 版本与调查不一致（`56d7.js` / `0425.js` 不在其中） |
  | 改 `docs/原版/` 里的任何内容 | 违规 | 一手证据只读，改了就没法复核 |
  | 对 jsxbin（`public/lib/all.decrypted.js`）声称读过实现 | 违规 | 仍不可读 |
  | `docs/原版/01-原版源码/panel/js/app.v4.js:37402` 这种行号锚点 | 合规 | 可直接复核 |

- **与既有 ADR 的关系**：
  - **取代 ADR-20**（ADR-20 正文保留，首行加状态行）。
  - **ADR-19 因此可复核**：它引的 `app.v4.js:37402-37532` 现在能当场打开验证（T-67 已按它完成三页迁移）。
  - **与 ADR-01 无关**：ADR-01 说的是 `public/lib/all.decrypted.js`（jsxbin）不逆向；本条说的是面板 Vue 源码入库。两件事，别混。
- **什么时候推翻**：入库源码与 `docs/` 现有调查结论**不再是同一版本**时（换版本要整目录替换并在 `docs/原版/README.md` §四记一行日期与来源），或版权要求撤下时（那时退回 ADR-20 的做法，但行号锚点仍按美化版记）。

## 后果


- 📌 **违反时的判据**：引用原版却不给 `文件:行号`；或按字符串定位给锚点；或有人改 `docs/原版/` 里的内容。

## Lessons Learned

- **ADR-20 当初的取舍是对的**：不入库确实换来了仓库体积与版权的安全，且「字符串定位」在只有压缩版的年代是唯一可用的复核手段 —— 它不是偷懒，是当时的最优解。
- **被高估的是「权宜」的寿命**：把「暂不」写成「决定」，让这条权宜状态存在了整整一天（2026-10-22 → 2026-10-23）就开始反噬 —— 文档里 31% 的边标着「未提取」，而生成物里全有。**前提一旦消失，权宜必须当天退役**，不能等「哪天想起来」。
- **可复用的判据**：一条 ADR 的「什么时候推翻」要写成**可观测事件**（「源码已入库」），而不是「拿到授权时」这种没有信号的措辞 —— 后者永远不会触发，ADR 就会永远有效地说谎。
