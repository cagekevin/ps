# ADR-0006 · 不引入 CSInterface.js

- **状态**：生效
- **结论**：不引入 CSInterface.js：自写 eval-script.ts 薄封装，官方库 1000+ 行且 evalScript 无 Promise 化与超时。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：只需要 evalScript / getSystemPath / 事件三样

## 背景

源文档（`docs/架构/决策记录.md`）本条未单列「背景」段：旧约定与原因写在「决定 / 原因 / 由来」字段里，已随「判据」段逐字搬来。

## 判据（它凭什么成立 / 为什么不成立）

- **决定**：自己写 `eval-script.ts` 薄封装，不用 Adobe 官方的 CSInterface。
- **原因**：只需要 `evalScript` / `getSystemPath` / 事件三样；官方库 1000+ 行，且它的 `evalScript` 没有 Promise 化和超时。
- **代价**：CEP 事件（选区变化、宿主消息）以后要自己实现。
- **什么时候推翻**：需要大量 CEP 事件时，可以引官方库只取事件部分。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果


- 📌 **违反时的判据**：`src/` 下出现 `CSInterface` import，或有人以「官方库更省事」为由引入它（需要它独有能力时先回来改本条）。
