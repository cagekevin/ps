# ADR-0008 · 样式数值只有一个来源

- **状态**：生效
- **结论**：样式数值只有一个来源：全部色值/字号/间距/圆角逐字进 tokens.css，组件只引用变量，style-guard 强制。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：原版 CSS 198KB 无作用域、色值散落

## 背景

源文档（`docs/架构/决策记录.md`）本条未单列「背景」段：旧约定与原因写在「决定 / 原因 / 由来」字段里，已随「判据」段逐字搬来。

## 判据（它凭什么成立 / 为什么不成立）

- **决定**：全部颜色/字号/间距/圆角/尺寸放 `src/styles/tokens.css`，组件里只引用变量，`style-guard` 强制。
- **原因**：原版 CSS 198KB 无作用域、色值散落，改一处要全局搜。
- **代价**：加新色值要走"先加 token 再用"两步。
- **什么时候推翻**：不推翻。需要主题切换时，加 `[data-theme]` 覆盖层即可，不用改组件。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果


- 📌 **违反时的判据**：组件样式里出现 `#hex` / `rgb()` / 裸 `px` 字号圆角（`npm run style:guard` 报出来的就是）；或出现第二个色值/尺寸来源。
