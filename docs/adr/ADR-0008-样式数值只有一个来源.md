# ADR-0008 · 样式数值只有一个来源

- **状态**：生效
- **结论**：样式数值只有一个来源：全部色值/字号/间距/圆角逐字进 tokens.css，组件只引用变量。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：原版 CSS 近 200KB 无作用域、色值散落

## 背景

原版样式无作用域、色值散落，改一处要全局搜。

## 判据

1. **全部颜色 / 字号 / 间距 / 圆角 / 尺寸放 `src/styles/tokens.css`**，组件里只引用变量。
2. **CSS 与脚本代码都算来源**：脚本里内联的色值同样是第二个来源（当前已知两处漏网），必须改成引用 token。

**唯一入口**：`src/styles/tokens.css`。

**现状（2026-10-26）**：本条**当前没有自动闸** —— 原先的样式守卫脚本已随删闸归档，`npm run check` 不再拦裸色值。样式层目前靠人工核对维持，已知缺口是脚本内联色值两处。**这是已知缺口，不是「已合规」。**

**禁止清单**

| 禁止 | 为什么 |
|---|---|
| 组件样式里出现裸色值 / 裸字号 / 裸圆角 | 第二份来源，改一处要全局搜 |
| 脚本里内联色值 | 同上，且样式守卫查不到这类 |
| 出现第二个色值 / 尺寸来源 | 判据无从落地 |

**代价**：加新色值要走「先加 token 再用」两步。

**什么时候推翻**：不推翻。需要主题切换时加一层覆盖即可，不用改组件。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果

- 📌 **违反时的判据**：出现第二个色值 / 尺寸来源；或组件与脚本里出现裸色值、裸字号、裸圆角。
