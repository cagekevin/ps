# ADR-0012 · 写原面板数据文件前先备份，字段类型统一

- **状态**：生效
- **结论**：写原面板数据文件前先备份到 .bak，星级统一写数字；写坏了没有第二个副本。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：原面板数据文件一旦写坏就没有第二个副本

## 背景

原面板的数据文件是用户资产，写坏了没有第二个副本 —— 原版自己的做法更糟：读坏文件会用默认值覆盖。

## 判据

1. **写原面板数据文件前先备份**（另存一份备份文件）。
2. **原文本身已坏时，不让坏内容顶备份** —— 另存一份隔离副本，保留原字节以便查原因。
3. **备份与隔离的判定只有一处**（判据见 ADR-0015 的落点）。
4. **字段类型统一**：星级一律写数字，不写字符串。

**唯一入口**：落盘与备份 = `src/cep/disk-write.ts`。

**禁止清单**

| 禁止 | 为什么 |
|---|---|
| 写文件前不备份 | 写坏了没有第二个副本 |
| 让坏内容顶备份 | 备份必须是好的那一版，否则是假退路 |
| 备份 / 隔离判定在两处各写一遍 | 同一判据两份实现，改一处就漂 |
| 星级写字符串 | 类型不统一，读侧要到处转型 |

**什么时候推翻**：不推翻。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果

- 📌 **违反时的判据**：写文件前没有备份；或坏内容被当成备份。
