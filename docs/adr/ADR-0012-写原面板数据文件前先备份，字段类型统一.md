# ADR-0012 · 写原面板数据文件前先备份，字段类型统一

- **状态**：生效
- **结论**：写原面板数据文件前先备份到 .bak，星级统一写数字；写坏了没有第二个副本。
- **日期**：2026-10-22（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：原文件里 star 有的写 "3" 有的写 3，混写会让原面板读不出

## 背景

源文档（`docs/架构/决策记录.md`）本条未单列「背景」段：旧约定与原因写在「决定 / 原因 / 由来」字段里，已随「判据」段逐字搬来。

## 判据（它凭什么成立 / 为什么不成立）

- **决定**：改 `sj_ztglStar.ini` / `sj_ztglTags.ini` 之前，先把原文写到 `<文件>.bak`；星级统一写**数字**。
- **原因**：这两个文件是原面板的资产（用户攒的收藏和标签）。原文件里 `star` 有的写 `"3"` 有的写 `3`，
  混着写回去会让原面板读不出来；写坏了没有第二个副本。
- **代价**：每次写多一次 IO（几十字节，可忽略）；`.bak` 只保留最近一次。
- **什么时候推翻**：等我们完全接管这两个文件、原面板不再读它们时，可以去掉备份。

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果


- 📌 **违反时的判据**：写 `sj_ztglStar.ini` / `sj_ztglTags.ini` 的代码路径上没有对应的 `.bak` 写回；或星级出现字符串写法。
