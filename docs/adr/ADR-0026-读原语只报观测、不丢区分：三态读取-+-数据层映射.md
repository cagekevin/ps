# ADR-0026 · 读原语只报观测、不丢区分：三态读取 + 数据层映射

- **状态**：生效
- **结论**：读原语只报观测不丢区分：不抛但必须带回原因的三态读取；判别位全仓一份，语义映射放数据层。
- **日期**：2026-10-23（取自源文档状态索引「定于」列，未逐条 git log -S 复核）
- **裁定人**：UNVERIFIED（源文档未记每条裁定人）
- **触发**：同一原语族里「区分被算出来又被扔掉」发生了两次

## 背景

读失败是常态（首次使用、文件被占用、同步盘没挂），不是异常。让读抛异常，只会逼每个调用点各写一次兜底，而兜底的默认写法就是丢掉原因 —— 只是把丢信息的地方从原语挪到调用点。

同一个原语族里「区分被算出来又被扔掉」发生过两次：两次都不是没算，是**原语的返回形状装不下三种状态**，信息被裁掉了。后果不是日志少一行，而是「写路径前置条件」整条失效 —— 读不到被说成「文件不存在」，写就会拿默认值覆盖用户文件，且没有备份。

## 判据

1. **错误模型：读不抛，但必须带回原因。** 读结果不许是两态，必须是带原因的形状。
2. **原语只报观测，不报结论。** 原语报告「在那个路径上看不到内容」以及**为什么看不到**（带原始错误码与文本）；原语**不许**把它翻译成用户可见结论（首次使用 / 文件坏了 / 可以给默认值 / 必须拒绝写）。同一观测由数据层按各自语义下结论。
   - **判断「查不到」只认错误码，不许用存在性探测。** 只认「文件不存在」这一种错误码；权限不足、文件被占用、网络盘错误**一律算错误**，不得算成「不存在」。
   - **取错误码直接用读取操作自己抛的码**，不要先做一次存在性检查再读 —— 多一次系统调用，且「判完到读之间文件变了」是一个真实的窗口。
   - **精度上限（已知残差）**：原厂脚本的文件探测没有错误码，权限与不存在都返回同一个假值；有 Node 时不影响结论，只有宿主没开 Node 时才退化成不精确。
3. **映射放在边界。** 读原语层给自己的三态形状，数据层给自己的读结果形状；**读原语层不许依赖数据层的形状**（那是反向依赖）。映射只发生在一个地方：数据层接原语的那个函数。
4. **判别位全仓一份（读链域）。** 「这次读成没成、坏在哪」在读链域（观测 → 语义 → 仓库 → 消费点）**只许一个判别位名、一套取值词表**：判别位叫 `status`，取值为「成功 / 查不到 / 出错」三态。**层与层之间不许各自造词**（不许一个层叫「成功/不存在/损坏」、另一个叫「是/否」）。层与层的差别只许体现在**臂数**上（仓库层把「首次使用」折成「可用 + 默认值」，所以是两态）——**词表不许分叉**。
   - **不同域不并进来**：脚本调用结果、命令执行结果、云同步结果是**另外三个域**，各有各的判别位与词表，不许为了"全仓一个词"把它们拉平 —— 那是把不同语义塞进同一个词表。
5. **一个判据，两个读入口。** 同步入口（宿主快路径）与异步入口（Node 优先、原厂脚本回退）。**判据只有一份**：两者共用同一个读取实现与同一个错误分类。**各自唯一的原因**：同步 —— 宿主里能同步读文件的只有 Node；异步 —— 两条路的合并策略只有一个正确位置，拆开就散。上层只能经这两个入口拿文件内容。
6. **写路径的前置条件是「读到过真数据」，不是「读没报错」。** 前置条件必须可判：读到过真实内容（或明确判定为「文件不存在」且该仓库允许首次建文件），否则拒绝写。**写失败一律抛**，不降级。

**唯一入口**：读原语层 = `src/cep/fs-read.ts`；数据层映射 = `src/cep/data/repo-read.ts`；仓库读结果形状 = `src/cep/data/types.ts`。

**禁止清单**

| 禁止 | 为什么 |
|---|---|
| 读原语返回两态（可空）给写路径用 | 三种状态装不下，调用方只能猜 |
| 读原语里判断「这算不算首次使用 / 要不要拒绝写」 | 结论属于数据层；原语只报观测与原因 |
| 用存在性探测判「文件不存在」 | 它对「存在但读不到」也返回假值 → 权限问题被当成首次使用 → 写路径覆盖用户文件 |
| 把权限类、占用类错误码归进「查不到」 | 「查不到」只许由「文件不存在」产生 |
| 读原语层依赖数据层的读结果形状 | 反向依赖 |
| 上层绕开读原语入口自己读文件 | 判据就无处落地 |
| 写路径前置条件写成「读没报错」 | 只证明没报错；任何一态被伪装成没报错就穿过去 |
| 读链域出现第二套判别位名或第二套取值词表 | 同一件事两种写法，判别与收口都无处落地 |
| 把脚本结果 / 命令结果 / 云结果的判别位拉平成读链的 | 不同域不同语义，合成一个词表就分不清"哪种失败" |

## 决议

决议即「判据」段各条判据本身；本条无独立例外或指向性补充。

## 后果

- 📌 **违反时的判据**：读原语返回两态给写路径用；读原语层依赖数据层形状；用存在性探测判「文件不存在」；上层绕开读原语入口自己读文件；读链域出现第二套判别位名或取值词表。
