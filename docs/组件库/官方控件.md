## 2. 设置页专用结构

证据：

- `docs/页面/08-设置.md:48`：折叠面板 7 键 `base / leftNav / shortcutKey / commonUse / fontSet / fontManage / sync`
- `docs/生成/页面规格/08-设置.md:82-94`：`open` 行、`最新更新`、`开启云同步预设`
- `docs/原版/02-组件文档/02-组件/Set_2.md`：`showMore` 七键、`syncTime`

结构：

```text
Set
├─ Member
├─ hr.line
├─ setTitle 使用设置
├─ open.use-setting-item
│  └─ list-hidden
├─ open.use-setting-item
│  └─ list-hidden
├─ ...
├─ open.use-setting-item
│  └─ list-hidden
│     最新更新：...
│     baseCheck 开启云同步预设
├─ clear_cache_bar
├─ hr.line
└─ 帮助更新 / 关于我们
```

关键 class：

| class | 官方实测 |
|---|---|
| `Set relative` | `padding:15px 0; position:relative` |
| `hr.line` | 高 1px；左右各 15px 缩进；半透明黑 |
| `setTitle` | 白色、12px、可点击、space-between |
| `use-setting-item` | `margin-top:5px; font-size:12px` |
| `list-hidden` | `padding:12px 10px; margin:6px 0; background:#222` |
| `app-padding` | `padding:0 0 0 10px` |

## 4. 结论

官方控件不是“每个页面自己一套”，而是：

- 基础控件固定；
- 页面只组合 `setTitle / open / list-hidden / app-padding`；
- 设置页所有区块共用同一折叠行；
- 不存在“云同步页专属标题 + 专属按钮”。

当前缺的不是提取，而是 `SettingsSection` 这一层没有建。
