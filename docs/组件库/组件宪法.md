# 组件宪法

> **只列 `src/components` 里真实存在的 props。**
> 表里没有的 prop = 不存在，写代码时不要臆想。
> 页面只能用这里登记的用法；需要新变体先走 `docs/规范/新控件准入.md`。

## PageShell

```ts
title: string
count?: string | number
```

插槽：

- 默认：内容
- `toolbar`
- `footer`
- `extra`

页面禁止自写 header / 背景 / 滚动区。

## GButton

```ts
type?: 'default' | 'primary' | 'danger' | 'text'
size?: 'small' | 'medium'
disabled?: boolean
loading?: boolean
block?: boolean
grid?: boolean
columns?: 1 | 2 | 3 | 4
drop?: 'before' | 'after'
removable?: boolean
```

禁止：

- 页面自定义 class 改高度、颜色、圆角；
- 新 `type`；
- 新 `size`；
- 原生 `<button>` 替代。

## CheckBox

```ts
modelValue: boolean
indeterminate?: boolean
disabled?: boolean
```

固定：

```text
14×14
12px 标签
4px 间距
```

没有 `size`，没有页面覆盖。

## GInput

```ts
modelValue: string
placeholder?: string
disabled?: boolean
clearable?: boolean
size?: 'small' | 'medium'
```

插槽：

- `prefix`
- `suffix`

事件：

- `clear`
- `enter`
- `blur`

## SelectBox

```ts
options: { id?: string | number; label: string }[]
modelValue: number
disabled?: boolean
```

事件：

- `update:modelValue`
- `choose`

页面不自己画下拉列表。

## GDropdown

```ts
placement?: 'bottom-start' | 'bottom-end' | 'top-start' | 'top-end'
visible: boolean
```

插槽：

- `trigger`
- 默认：面板内容，作用域含 `close`

定位、翻转、点外部关闭全由组件负责。

## GMenu / GMenuItem

GMenu：

```ts
modelValue?: string | number
```

事件：

```ts
select(value: string | number)
```

GMenuItem：

```ts
value: string | number
disabled?: boolean
```

页面不写菜单项 hover / active / 高度。

## GPopover

```ts
placement?: FloatingPlacement
offset?: number
padding?: number
matchWidth?: 'width' | 'min' | false
role?: 'menu' | 'listbox' | 'dialog'
disabled?: boolean
closeOnOutside?: boolean
closeOnEscape?: boolean
panelClass?: string
open: boolean
```

插槽：

- `trigger`（作用域含 `open`）
- 默认（作用域含 `close`）

新浮层先接它，不写 `position: absolute`。

## GTooltip

```ts
content: string
placement?: 'top' | 'bottom'
delay?: number
```

## CepModal

```ts
title?: string
width?: number
okText?: string
cancelText?: string
hideCancel?: boolean
visible: boolean
```

事件：

- `ok`
- `cancel`

页面禁止自写遮罩、标题栏、footer。

## SettingsSection

```ts
title: string
defaultOpen?: boolean
```

默认插槽：设置内容。

只用于设置页。页面不复制箭头、背景、间距。

## BaseGroup

```ts
text: string
value: boolean
```

事件：

- `change`
- `menu`
- `ctrl`

插槽：

- `header`
- 默认内容

只用于动作页分组。

## ActionGrid

```ts
items: GridItem[]
columns: number
showIcon?: boolean
showText?: boolean
removable?: boolean
draggable?: boolean
itemClass?: (item, index) => string
```

事件：

- `run(item, event)`
- `menu(event, item, index)`
- `remove(item, index)`
- `dragstart` / `dragover` / `drop` / `dragend`

只负责网格和事件，不负责业务执行。

## Icon

```ts
name: string
size?: IconSize | number | string
color?: string
title?: string
```

`size` 预设：

```text
3xs 2xs xs sm md lg xl 2xl
```

默认 `1em`，跟随字号。不要写裸 px。

## NewSpin

```ts
size?: number
tip?: string
show?: boolean
mask?: boolean
```

## BackTop

```ts
target?: string
threshold?: number
icon?: string
```

## Toast / TaskHud

由 store 驱动，不作为页面控件直接使用：

- `useFeedbackStore().ok/error/warn/info`
- `useTaskStore()`

## 页面硬规则

1. 页面不允许 `<button>` / `<input>` / `<select>`。
2. 页面不允许新颜色、字号、圆角。
3. 页面不允许 `:deep()`。
4. 页面不允许自写弹窗遮罩。
5. 页面只能从本表选 props。
6. 需要新 prop / 新变体 → 先报备，不先加。
