## 6. 审核时要看什么

用户只审四件事：

1. 页面结构是不是官方结构；
2. 组件清单里有没有自造件；
3. 页面 CSS 是不是“无”；
4. 有没有未批准的新控件。

四项有任何一项不对，不批准。

## 7. 违规判定

- 没报备就写页面：回滚；
- 批准的是 A 结构，做成 B：回滚；
- 页面 CSS 写了按钮/输入框/颜色：回滚；
- 新控件没单列：回滚；
- 用“删重复”“修 bug”绕过报备：回滚。

### 外壳与滚动（定案）

**结论：不用 `PageShell`。** 依据：`PageShell` 的 header 是 `v-if`（`components/PageShell.vue:21`）、body 是 `overflow:hidden`（`:104`），不传 `title` 时它只剩一个裁剪壳，滚动仍要页面自己给——那不如直接让页面根当滚动容器。
本页整页就是一个滚动面（官方 `.CommonUse{overflow-y:auto}`），与 `/fontSet`（`pages/fontSet/index.vue:498` 根滚动）**同一支实现**，不新开第三支；子面板内部**不许再开滚动**（否则就是"同一页两样子"）。收敛方向记在 D-47：全仓统一"页面根滚动"，`PageShell` 只保留 header/底栏两个可选槽位，不再自带 body 滚动。

### 页面 CSS

**优先"无"**：布局全部用 `u-*` 工具类 + 组件自带样式。必须写的只有三条，且只用 token：
