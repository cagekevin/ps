## 6. 审核时要看什么

用户只审四件事：

1. 页面结构是不是官方结构；
2. 组件清单里有没有自造件；
3. 页面 CSS 是不是“无”；
4. 有没有未批准的新控件。

四项有任何一项不对，不批准。

## 7. 违规判定

- 没报备就写页面：回滚；
- 批准的是 A 结构，做成 B：回滚；
- 页面 CSS 写了按钮/输入框/颜色：回滚；
- 新控件没单列：回滚；
- 用“删重复”“修 bug”绕过报备：回滚。
