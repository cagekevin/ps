# 页面模板

> 新页面只能从这三种结构起步。  
> 模板里的组件必须存在于 `docs/组件库/组件宪法.md`。  
> 页面 CSS 默认“无”；需要布局时才允许用 token。

## 0. 脚手架

```bash
npm run new:page -- --template=settings --route=/foo --name=foo --title=标题
```

可选模板：

```text
settings
list
detail
```

脚本会：

- 创建 `src/pages/<name>/index.vue`；
- 插入路由；
- 不生成页面级按钮/输入框/颜色样式。

先看生成内容：

```bash
npm run new:page -- --template=settings --route=/foo --name=foo --dry-run
```

## 1. SettingsPage

适用：

- `/set`
- 以后的设置类页面

```vue
<PageShell title="设置">
  <SettingsSection title="使用设置" :default-open="true">
    <!-- 设置项 -->
  </SettingsSection>

  <SettingsSection title="云同步设置">
    <CheckBox v-model="enabled">开启云同步预设</CheckBox>
  </SettingsSection>
</PageShell>
```

规则：

- 只用 `SettingsSection`；
- 不写 `h2`；
- 不写箭头；
- 不写内容背景；
- 不在页面里写按钮皮肤。

## 2. ListPage

适用：

- 字体管理
- 动作
- 以后所有列表

```vue
<PageShell title="列表" :count="items.length">
  <template #toolbar>
    <GInput v-model="keyword" placeholder="搜索" clearable />
    <GButton size="small">操作</GButton>
  </template>

  <div class="list">
    <!-- 行内容 -->
  </div>
</PageShell>
```

规则：

- 列表行可以有页面布局；
- 行内按钮用 `GButton`；
- 空态用统一 `EmptyState`（待抽象）；
- 不自己写滚动容器。

## 3. DetailPage

适用：

- 详情
- 表单
- 单一对象编辑

```vue
<PageShell title="详情">
  <div class="detail">
    <GInput v-model="name" placeholder="名称" />
    <GButton type="primary" block>保存</GButton>
  </div>
</PageShell>
```

## 4. 控件总览模板

实际源码：

```text
src/pages/_atoms/index.vue
```

路由：

```text
#/__atoms
```

用途：

- 查已有控件；
- 查允许的用法；
- 查页面不该写什么。

## 5. 模板准入

新增模板类型需要：

1. 说明适用页面；
2. 至少两个真实页面会使用；
3. 画 ASCII；
4. 用户批准页面契约；
5. 不允许先建“以后可能用”的模板。

## 6. 模板禁止项

- 模板里出现页面级按钮样式；
- 模板里出现自定义弹窗；
- 模板里出现未登记组件；
- 模板里出现 `:deep()`；
- 模板里出现裸颜色/字号/圆角；
- 模板只加不删旧实现。
