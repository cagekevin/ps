## 已删除的重复

| 重复 | 处理 |
|---|---|
| `FontSetCheck` | 已合并到公共 `CheckBox`，页面私有组件删除 |
| 设置页自写 `.cloud-sync__*` | 已删除，改用 `SettingsSection` |

## 仍存在的重复

当前没有可直接删除的重复组件。

`ActionGrid` 已使用 `GButton` 的 `grid` 变体；空态已统一到公共 `EmptyState`。

## 不是重复，不能硬删

| 组件 | 证据 | 结论 |
|---|---|---|
| `DistributedDialog` | 有 pin、回车确认、高级用法、固定不关闭 | 不是 `CepModal` 的重复；硬删会丢交互 |
| `TagMenu` | 标签选择/创建浮层 | 不是菜单，不能和 `TagContextMenu` 合并 |
| `TagContextMenu` | 重命名/删除菜单，内部已用 `GMenu` | 不是标签选择器 |
| `GPopover` | 通用浮层壳 | 不是 `GDropdown` 的重复；`GDropdown` 是下拉特化 |
| `FontSetSelect` | 支持搜索、重命名、删除、plain 触发器 | 是 `SelectBox` 的功能超集，不能直接删 |
| `GButton` | 应用级按钮 | 页面按钮应改用它，不是删 `GButton` |

## P0 缺口

### `SettingsSection`

阻挡：

- `/set` 无法按官方手风琴结构；
- 每个设置项会继续自写标题、箭头、内容缩进。

必须先申请、画 ASCII、用户批准。

### 通用空态

阻挡：

- 字体管理、动作、设置各自写空态；
- 字号/颜色/间距不一致。

## P1 缺口

- `Tabs`
- `TagInput`
- `SearchInput`
- `ListLoading`
- `VersionSwitcher`
- `DeviceModal`

## 明确禁止

- 页面新增按钮样式；
- 页面新增勾选框样式；
- 页面新增弹窗遮罩；
- 页面新增 `__title` / `__row` / `__actions` 结构类；
- 用“视觉统一”当理由绕过准入。

## 设置页正确结构

```text
PageShell
└─ SettingsSection（待批准）
   ├─ 使用设置
   ├─ 基本设置
   ├─ 左侧栏菜单
   ├─ 快捷键设置
   ├─ 常用功能面板
   ├─ 字体面板
   └─ 云同步设置
       ├─ 最新更新
       └─ CheckBox 开启云同步预设
```

在 `SettingsSection` 批准前，`/set` 不再改视觉。
