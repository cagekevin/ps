## 一、GRadio（单选项）

**① 原版出处（官方确有这件）**
- 官方 `baseRadio` 在本页出现 **9 次**：`comembed` 3 次（嵌入时链接方式三选一，`docs/生成/页面规格/05-常用.md:103-108`）、`comexport` 4 次（桌面/文件所在目录 ×2 组，`:275-278`、`:291-294`）、`comspacing` 2 次（按图层/按坐标排序，`:427-430`）。
- **官方样式值：查不到**。查过：`app.bf68b505.css` 搜 `.radiobox` / `.ant-radio` / `.radio_box`（后者位置 155396 属设置页另一处）；`app.v4.js` 搜 `staticClass: "radio…"` 只命中 `radio_box`（`:58907`，别处）；`baseRadio` 的 render 不在 `app.v4.js`。

**② 现有件排查（查了三层）**
- 第 1 层 `src/components/` 顶层 28 个 `.vue`：**无**单选项（`CheckBox.vue` 是勾选，`SelectBox.vue` 是下拉，`MultiTabs.vue` 是多选）。
- 第 2 层 各页私有 `components/` 共 **7 个目录、34 个 `.vue`**（fontManage 10 / fontSet 12 / action 2 / freePanel 4 / rename 2 / set 3 / style 1）：命中 **`fontSet/components/FontSetRadio.vue`**，被 `CreateButtonPanel.vue:5` import、`:68-69` 使用两次。
- 第 3 层 关键词 `Radio` / `Switcher` / `Switch`：`Radio` 只命中上面两个文件；`Switch` 命中 `MultiTabs.vue`、`RenameModeTabs.vue`（两者都不是单选圆圈）。
- 结论：**有一份私有件，但不能跨页引用**（引用别人的页面私有件 ≠ 同一份）。

**③ 长得什么样**
```
○ 文字         ← 普通
● 文字         ← 选中（圆圈填色）
[整行变淡]      ← 灰掉
```
一行一个圆圈 + 右侧文字；圆圈约 10×10，圆圈与文字间留 4；点击任意位置都选中。

**④ 数据从哪来、状态有哪些**
`v-model`（一个值）+ 每颗 `value`；同组共享一个 model。状态：普通 / 悬停 / 按下 / 选中 / 灰掉 / 聚焦（键盘）。**悬停与按下官方未规定**（见尺寸表 §4-1）。

**⑤ 放哪、性质、与现有一份的关系**
公共 `src/components/GRadio.vue`。与 `FontSetRadio.vue` 关系：**并存、待合并**（值照抄 FontSetRadio：圆圈 10、间距 4、字号 12、选中用强调色）；登记欠债 **D-48**（合并条件：`/fontSet` 解冻后 `CreateButtonPanel` 改用 `GRadio`、删私有件）。

## 二、功能格（本页 14 个）

**① 原版出处**
- 官方每格占宽 33%、上方间距 15（`.context-one-wrap`，CSS 位置 110803；`05-常用.md:35642` 实测列）。
- 图标块 **32×32、圆角 10、底色 #222**（`05-常用.md:35671` 实测列；注意全局 `.context-svg-wrap` 是 50×50，本页被覆盖成 32，见尺寸表 §2-1）。
- 右上角标：3×3 小点，上移 30、左移 -3（`.mark`，CSS 位置 110725）。

- 悬停：图标变蓝 `#006fff`（`.context-svg-wrap:hover svg`，位置 110327），同时换第二图标（`app.v4.js:35708-35711`）。

**② 现有件排查（查了三层）**
- 第 1 层：`ActionGrid.vue`（渲染 24px 横条按钮 + `GButton.is-grid`）、`GButton.vue`（`is-grid` 变体）。**都不符**：官方是 32×32 圆角方块 + 下方文字，`ActionGrid` 是 24px 横条。
- 第 2 层：`freePanel/components/FreePanel.vue`、`FreePanelBlock.vue` 在用 `ActionGrid`（同一份 24px 横条）。
- 第 3 层 关键词 `Tile` / `Grid`：`Tile` **0 命中**（`GTile` 已随 T-80 删除）；`Grid` 命中 `ActionGrid`/`CommandGrid`/`FreePanel`/`GButton`/`useLongPressDrag`，均非同形。
- 结论：没有可用的同类件，且**改用 `ActionGrid` 会改到冻结页外观**（它服务 `/freePanel`）。

**③ 长得什么样**
```
┌────┐
│ ▨  │ ← 32×32 圆角方块，图标居中；右上角 3×3 小点
└────┘
```

**④ 数据从哪来、状态有哪些**

**⑤ 放哪、性质、与现有一份的关系**

**② 现有件排查（查了三层）**

- 第 2 层：`rename/components/RenameModeTabs.vue`——**页面私有分段切换，但它对应的是另一条官方规则**（`.top-switch` 高 37、底 #282828、选中下边框蓝，见 `RenameModeTabs.vue:4-8`），与本页的 `.switch-wrap/.switch-shape`（38/24/圆角 5）**不是同一个控件**。

**③ 长得什么样**

**④ 数据从哪来、状态有哪些**

**⑤ 放哪、性质、与现有一份的关系**

**与 T-80 删掉那份的差别**：① 宽度改为**按段数算**（旧版写死 `flex:1` + 左右内空 12，两颗时会比官方宽）；② 高度按官方 24 + 外框 38（旧版用 `--h-control-sm`）；③ 圆角按官方 5（旧版用 `--r-input`）；④ 结构上不再自带 `role="radiogroup"` 之外的额外槽位；⑤ **选中态仍然是 UNVERIFIED**——旧版就注明"原版 `.switch-shape` 没有选中态规则"，这次同样没有新证据，不许编。与 `MultiTabs.vue`：**并存**（多选 vs 单选）；与 `RenameModeTabs.vue`：**并存**（官方两条不同规则），欠债 **D-49**（两页解冻后统一命名与皮肤）。

## 五、反过来考自己三问
1. **哪件我不确定官方真的要**：**GRadio**。官方 render 里确实有 9 处 `baseRadio`（`05-常用.md:103-108`、`:275-278`、`:291-294`、`:427-430`），所以"官方有"是确定的；**不确定的是它的长相**——样式值一条都读不到（§一②）。也就是说：官方要这个**功能**确定，这件**控件**长什么样是我们按 `FontSetRadio` 定的。
2. **最可能又变成"两份长得像"的**：`GSegment`。它旁边已经有一个 `RenameModeTabs`（同样"一排等分小块 + 选中态"），两者对应官方两条不同规则、外观都带 #282828 底——**极易被后人当成重复而误合并，或反过来各改各的**。防线：两个文件头都写明对应哪条官方规则（`.switch-wrap/.switch-shape` vs `.top-switch`），并用 D-49 钉住"解冻后统一"。
3. **一句话说清为什么这四个要单独建**："这一页有 9 个单选、14 个功能格、1 个九宫格、1 个段选，现有件里没有一件对得上官方的形状——**新建是为了让这 25 处共用一个数，而不是各画一遍**。" 反过来说：如果哪一件只有 1 处用、且现有件改一点就能用，那它就是多余的，不该建。
