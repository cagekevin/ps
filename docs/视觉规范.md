# 视觉规范

> 字号、图标、图标与文字的组合方式。**写页面之前先查这张表，不要自己定。**
>
> 强制方式：`npm run check` 会拦「裸色值 / 裸字号 / 裸圆角 / 图标裸尺寸」。
> 依据来自原版 CSS 和模板的真实使用频率，不是拍脑袋（见每节的数据来源）。

---

## 一、字号阶梯

| token | 值 | 场景 |
|---|---|---|
| `--fs-xs` | 10px | 极小的辅助说明（如「大预览」） |
| `--fs-sm` | 11px | 计数、次要信息、chip 内小字 |
| `--fs-md` | **12px** | **正文默认**（原版用了 129 次，绝对主力） |
| `--fs-lg` | 13px | 页面标题、弹窗标题 |
| `--fs-base` | 14px | 工具条图标按钮的字号 |
| `--fs-xl` | 15px | 大按钮、强调 |
| `--fs-name` | 16px | 无预览模式下的字体家族名 |
| `--fs-2xl` | 18px | 少见，标题强调 |

字体预览另有专用档位：`--preview-sm/md/lg/xl`（24/38/50/72），由预览模式切换，不要用在普通文字上。

## 二、图标阶梯

| token | 值 | 场景 | 原版使用次数 |
|---|---|---|---|
| `--icon-2xs` | 9px | 辅助小标、chip 内的勾 | 8 |
| `--icon-xs` | 10px | **密集列表内的操作图标**（hover 操作区、勾选） | 10 |
| `--icon-sm` | 14px | 按钮、工具条、输入框前缀、toast | 9 |
| `--icon-md` | **16px** | **默认**（最高频） | 12 |
| `--icon-lg` | 18px | 导航、页面标题旁 | 5 |
| `--icon-xl` | 20px | 强调 | 4 |
| `--icon-2xl` | 24px | 空态、大图标 | 1 |

**图标尺寸不跟字号绑定。** 12px 的文字配 14px 图标是正常的——图标视觉重量和字形不同，绑死会导致图标看起来偏小。

用法：

```vue
<Icon name="iconbiaoqian" size="xs" />   <!-- 推荐：预设名 -->
<GIcon name="iconbiaoqian" size="xs" />  <!-- 同上，语义更明确 -->
```

**不要写 `:size="12"`**，`npm run check` 会拦（能自动映射成预设名的会由 `npm run style:fix` 改掉）。

## 三、图标 + 文字

原版的答案是 **flex 容器 + `align-items: center`**（`.f-baseX`），不用 `vertical-align`，不用 `line-height` 硬凑。

### 四种结构

**① 前缀图标**（图标在文字前）

```html
<div class="u-row u-gap-3">
  <Icon name="iconbiaoqian" size="xs" />
  <span>我的标签</span>
</div>
```

**② 后缀图标**（图标在文字后，如下拉箭头）

```html
<div class="u-row u-gap-2">
  <span>全部语言</span>
  <Icon name="iconxiala" size="xs" />
</div>
```

**③ 纯图标按钮**（固定盒子居中）

```css
.icon-btn {
  width: var(--h-control-sm);
  height: var(--h-control-sm);
  display: inline-flex;
  align-items: center;
  justify-content: center;
}
```

**④ 三段式**（图标 | 文字伸缩 | 尾部元素）

```html
<div class="u-row u-gap-2">
  <span class="a-mark">A</span>
  <span class="list-count">全部(259)</span>   <!-- flex: 1; min-width: 0 -->
  <button class="clear-tag">取消筛选</button>  <!-- flex: 0 0 auto -->
</div>
```

### 四条硬规则

| 规则 | 原因 |
|---|---|
| 图标和文字**必须在 flex 容器里** | `<svg>` 是 inline 元素，和文字混排会按基线对齐，底部多出 3~4px 空隙 |
| 图标 `flex: 0 0 auto` | 否则容器变窄时图标被压扁（`Icon.vue` 已内置） |
| 文字 `min-width: 0` + `text-overflow: ellipsis` | 否则长文本撑破容器 |
| 间距用 `gap`，不用 `margin` | 见下节 |

### 图标着色

`fill: currentColor`，跟着父级 `color` 走，hover 自动变色。**不要**引入原版的 `.svgfill` / `.svgColor0-7` 预设色类。

## 四、间距阶梯

| token | 值 | 用途 |
|---|---|---|
| `--sp-1` | 2px | 极紧（图标与徽标） |
| `--sp-2` | 4px | 图标与文字、chip 之间 |
| `--sp-3` | 6px | 分组标题、菜单项内 |
| `--sp-4` | 8px | 区块内边距、工具条 |
| `--sp-5` | 12px | 区块间距 |
| `--sp-6` | 16px | 大区块 |
| `--sp-7` | 24px | 空态、页面级留白 |

布局用 `u-gap-1..6` utility，不要写 `margin-right`。

---

## 五、三处故意不照抄原版

| 原版做法 | 我们 | 理由 |
|---|---|---|
| `margin-right: 5px` 出间距（`gap` 用了 0 次） | `gap: var(--sp-3)` | ① 原版不用 gap 是 2019 年的浏览器限制，CEP 12 是 Chromium 99 ② margin 会在最后一个元素留空白，还得 `:last-child` 清零 |
| 间距 4/5/6/8/10 五种并存 | 4/6/8 三种 | 5 和 10 不在 8px 栅格里，硬加会破坏节奏 |
| `.svgfill` + `.svgColor0-7` 八个预设色类 | `fill: currentColor` | 预设色类只能用在固定场景；`currentColor` 跟着文字色走，hover 自动变 |

这三条已记入 `docs/架构决策.md` ADR-13。

## 六、常见错误

```vue
<!-- ✗ 图标裸尺寸 -->
<Icon name="iconbiaoqian" :size="12" />

<!-- ✗ 用 vertical-align 对齐图标和文字 -->
<span style="vertical-align: middle">文字</span>

<!-- ✗ 用 margin 做图标间距，最后一个会多出空白 -->
<Icon style="margin-right: 6px" />

<!-- ✓ -->
<div class="u-row u-gap-3">
  <Icon name="iconbiaoqian" size="xs" />
  <span>文字</span>
</div>
```
