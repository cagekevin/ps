# 记一下

> 一句话：**一份状态只写一处**。动手前先认领落点，别在几处各记一遍（几处都记 = 迟早不一致）。

1. **做了什么 / 踩了什么坑** → `docs/日志/`（一篇一文件，文件名带日期，平铺）
   - 新建：`node scripts/log.mjs new "<主题>"`（模板已含「背景 / 做了什么 / 结论」）
   - 重建索引：`npm run log:index`（`docs/日志/index.md` 是**产物**，禁手改）
   - 只在**决策 / 踩坑 / 架构变更**时写；日常改动不写。
2. **决策与判据** → `docs/adr/`：`node scripts/adr.mjs add --title "…" --conclusion "…" --user-approved`
   （一条一文件；索引由 `node scripts/adr.mjs index --write` 生成，**禁手改**；六问答卷由 AI 贴给用户看、**由用户拍板**）
3. **区域过程 / 轮次** → `daily/架构日志/<NN>-<区域>-<YYYY-MM-DD>.md`（债的锚点写这里）
4. **待办 / 债** → `daily/架构日志/债务.md`（**唯一写入口 = `node scripts/debt.mjs`**）
   - 登记：`node scripts/debt.mjs add --area NN --summary "…" --anchor "<区域日志文件名>"`
   - 改状态：`node scripts/debt.mjs resolve <TD-ID> --status 已解决 --note "…"`（**就地改，不追行**）
   - 体检：`node scripts/debt.mjs audit`；校验：`npm run ledger`
5. **任务** → `daily/架构日志/00-任务-总索引.md`（`T-xx`，手改这个文件；代码里 `TODO(T-xx)` 靠 `npm run ledger` 对得上）
6. **页面状态** → `docs/状态/进度.md`（每页做到哪、缺什么）；**页面验收** → `docs/页面/0N-*.md`（原版 vs 我方逐项）

> 落点不确定时，先看仓库根 `AGENTS.md` 的「文档分工」表与 `docs/架构/目标架构.md`。
> 本仓分层：`src/domain`（纯函数与类型，零 IO 零 Vue）· `src/cep`（**唯一 PS 出口**）· `src/commands`（命令注册表与分域命令）· `src/stores`（只读投影）· `src/composables` · `src/components`（跨页，`G` 前缀 = 基础件）· `src/pages`（11 页 + `_atoms` `_probe` `_placeholder`）。
