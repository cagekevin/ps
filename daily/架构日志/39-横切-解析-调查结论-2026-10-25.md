## 3. 五条判据（「解析」横切收口 = 五条同时成立）

> 每条一条命令能复算；判据 2 / 4 是**区分"真收口"和"看起来收口"**的两条，判据 5 **覆盖没想到的形态**。

**判据 1 · 单通道（解析只能有一个入口）**
不可信原文 → 可信形状只能经 `Decoder<T>` 契约（`decode` 必填，`| null` 不存在）。
```bash
grep -rn "JSON.parse(" src/ --include=*.ts | grep -v "JSON.parse(JSON.stringify" | grep -vE ":[0-9]+: *(\*|//)" | wc -l   # 现 16
grep -rn "JSON.parse(" src/cep/data/repo-read.ts | wc -l        # 现 1（唯一通道）
```
**收口 = 解析点收敛到通道内**；`JSON.parse` 裸用处数只许降不许升。

**判据 2 · 失败取不到值（真收口的第一判据）**
`ok:false` / `DecodeFail` 那一臂上，类型层**取不到 `.value/.groups/.list`**。真收口是**编译期红**，不是运行时判。
```bash
npx vue-tsc --noEmit       # 往任一失败臂补取 value ⇒ 这里红 ⇒ 真收口
```
**"看起来收口"的判据**：靠 `if (ok) return value` 的运行时约定 ⇒ typecheck 不红 ⇒ 假收口。

**判据 3 · 无自由文本失败（生产者不写用户话）**
失败臂只许**枚举码** + 观测（`field/expected/actual`）；中文渲染只在 `describeDecodeFail` 一处。
```bash
grep -rn "fail: '" src/ --include=*.ts | grep "[一-龥]" | wc -l      # 现 0，收口后仍须 0
grep -rnE "reason: '[^']*'|fail: '[^']*'|note: '[^']*'" src/ --include=*.ts | wc -l   # 现 18，只许降
```

**判据 4 · 无「可忽略字段」（真收口的第二判据）**
`ok:true` 臂上不许有"坏了也能照常取值"的旁路字段（`degraded/note/reason: string`）；`Decoded<T>` 只许 `degraded?: string` 且**带值即降级信号**。
```bash
grep -rn "  ok: boolean\|  degraded: string\|  note: string\|  reason: string" src/ --include=*.ts | wc -l   # 现 13，收口须 0
```
真收口 = 失败在类型上取不到值；假收口 = 失败能被无视（`note: string` 空串正常、非空是坏，但 `.groups` 永远可取）。

**判据 5 · 判别语法 = 1 种（覆盖没想到的形态）**
"这个解析结果成没成"只能有**一种判别语法**。现 11 形态 / 10 字段名 ⇒ 未收口。
```bash
{ ...| sort -u | wc -l }    # ① 字段名种数：现 10，收口须 1
bash 形态命令组             # ② 形态种数：现 11，收口须 1
```
**修正口径**：收口后 ①=`1` 且 ②=`1`；"只许降"测的是 ①② 的**去重后种数**，不是原始行数。行数降而种数不降 = 假收口。

## 4. 按刀 1 四层的分层结论（哪些形状该被同一条判据管住，哪些是合理分层）

**四层判据（刀 1 原文）**：问它「失败了说不出原因」会不会伤人 —— ① 说不出原因=只报 errno（**可以**）；②③④ 说不出原因=**不行**。
**处置规则**：① 只许两个（文本/字节）；② 只许一个入口一个形状（`readRepoFile`+`RepoRead`）；③ 只许一个契约（`Decoded|DecodeFail`）；④ 允许存在但必须有判别位、不许带可忽略字段。**判据：层数=形状数=入口数。**

## 5. 补角度 · 被搬走但没消灭（消债三问）

**Q1 · 失败去哪了？** 大部分有去向（`repo-read.ts` 读失败一律 `log.error` + `reason`，两处都有信号）；

**Q2 · 复杂度去哪了？** 真降了一段：`readRepoFile` 的 `decode` 必填把"12/13 个仓库各写 `JSON.parse` 结果直接当 T"收成一条通道。

**Q3 · 验证去哪了？** `decode` 侧有双向断言用例（见 38 号文 §3）；但**"别处不许再写一份裸 parse"零覆盖**，
