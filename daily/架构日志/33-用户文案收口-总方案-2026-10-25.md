- **算**：这句话是**系统在报告一次事件的结果或状态**——失败 / 降级 / 成功 / 进度 / 要用户做什么 / 问用户确认。

### 3.1 P3 · 页面/组件层提示语收进 `msg.*`（**口径订正：只收多处引用的**）

**目标（订正版）**：页面/组件层**多处引用的**提示语（同一句在 >1 处定义/引用）收进 `msg.<ns>.<key>`；
**单引用页面私有文案留页面**（不进公共层）。确认问句→`msg.confirm.fn`、成功回报→`msg.success.*`、
失败/校验→`msg.validate.*`/`msg.command.*`、多引用空态/进度/降级→`msg.page`。

**口径订正（2026-10-25，搬完才算清的账）**：原判据"页面层真提示语字面量归零"**过严**——它逼着单引用的
页面私有文案也进 `messages.ts`，制造 1→1 搬家账（见 §3.7）。订正为：**"页面不自拼多处引用的提示语"**。
判据一句话：**同一句提示语在 >1 处出现 = 该收进 `messages.ts`（N→1，真收口）；只在 1 处出现 = 留页面（1→1，留着）**。
（AGENTS.md 硬规则"拿不准放页面私有目录、别提前放公共"本就是这个意思。）

**⚠️ 判据（当场跑过，跑得出的数）**——完成判据 = 页面层**同文案>1 次的提示语 = 0**：

```bash
# 判据①：页面层中文提示语字面量里，同文案出现 >1 次的（= 该收进 messages.ts 的多引用）
# 当场实测：页面层 7 处中文字面量、去重 7 种、同文案>1 次 = 0 ✅
python3 -c "
import re,os
from collections import Counter
texts=[]
for base in ('src/pages','src/components'):
  for root,_,fs in os.walk(base):
    for f in fs:
      if f.endswith(('.ts','.vue')):
        t=open(os.path.join(root,f),encoding='utf-8').read()
        for m in re.finditer(r'(?:feedback\.(?:ok|error|warn|info)|\.run)\(\s*(?:[^,()]*,\s*)?[\'\"\`]([^\'\"\`]*[\u4e00-\u9fa5][^\'\"\`]*)[\'\"\`]', t):
            texts.append(m.group(1))
c=Counter(texts)
print('多引用(该收):', sum(1 for v,n in c.items() if n>1))
```

### 3.4 P5 · 防回潮（静态闸拦新增）—— **判不做 · 留痕**

**结论：本阶段不做，判「不做」并留痕。** 不写"已完成"——这是**取证后判定这条路错**，不是漏做，也不是做完了。

**为什么不做（三条，均为取证结论，非偷懒）**：
1. **提示语的语义机器判不了**（七步法 Step 1 证伪）：判据是「这句话回答『刚才发生了什么』才算提示语」——这是**语义判断**，`copy-audit` 只能给候选、语义归 `expected.json` 人工核定。要机器拦"新增提示语"，必然退化成"拦所有中文字面量"，误伤按钮标签/字段名（判不搬项）。
2. **现有闸不覆盖这条语义**（Step 0 普查）：`lint` 判层边界/断言/转型、`template-guard` 只判运行时炸的属性名（明令禁扩成风格检查）、`style-guard` 判 CSS 裸值、`copy-audit` 是纯计数器（无 exit code）。四道闸没有一道管"中文提示语语义"，硬塞进任一个都是语义错位。
3. **造闸 = 新债 + 白名单母体**（A4 + 减二）：新 guard 是**加法**（复杂度不降反升，减二不达标）；而"逐行具名放行白名单"正是 A4 判的**母体**（漏一项悄悄放行、看得不出）。已试造 `prompt-guard.mjs` 并当场拆掉（恒绿假凭证 + A4 白名单母体 + 不见重复的闸）。

**代价（如实留痕，不藏）**：防回潮当前 = **0**。下一个人在页面写一句**不重复**的新中文提示，静态面无人会红（4.1 只抓重复、`_notCounted` 是手填不自动响、`copy-audit` 4.2 会多一行但不作判据）。这是**已知且接受的缺口**，靠 `messages.ts` 唯一出处 + `expected.json` 人工核 + code review 兜。

**真要补的落法（未做，留待授权；不造第 6 guard、不手写白名单母体）**：把"页面层中文提示语字面量计数"作为一个**计数型基线**（`count > allowed` 即红、只许减不许增、`--update` 收紧），挂进**已有的计数器** `copy-audit.mjs` 加 `--check`（消费它自己算的 4.2，不吃手填数字，符合"只读=不手填"边界）——判据是"总数不许涨"，不是逐行具名白名单，故不触发 A4。**执行需单独授权（动 `copy-audit.mjs`），本阶段不做。**
