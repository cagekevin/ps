## 二-A4 · 盲区 25 · `userDirOnce()` 把一次失败**永久缓存**成空串

**第一遍漏的原因**：只查"路径怎么拼"，没查"拼不出来那次会不会被记住"。

```bash
sed -n '282,292p' src/pages/style/index.vue
```
```ts
let cachedUserDir: string | null = null
function userDirOnce(): string {
  if (cachedUserDir === null) {
    try { cachedUserDir = userDir() } catch { cachedUserDir = '' }   // ← 失败也进缓存
  }
  return cachedUserDir
}
```

**现象**：`userDir()` 抛一次（Node 桥瞬断 / `nodeRequire('path')` 抛 `NO_NODE`）⇒ `cachedUserDir = ''` 被**永久缓存**
⇒ 之后每次 `userFileSrc()` 都返回 `''` ⇒ **整页缩略图再也不显示，且没有任何重试路径**（缓存没有失效机制）。
注释自己写了理由（"每次都要过 CEP 的 Node 桥…会把渲染拖成同步桥调用风暴"）—— **性能理由成立，但失败态没被区分**：
"桥瞬断"和"浏览器 dev 没 Node"被折成同一个 `''`，而后者是**永远**拿不到，前者是**这次**没拿到。

**证据命令**：上 + `grep -n "cachedUserDir" src/pages/style/index.vue`。

**用户能感知的后果**：偶发的 Node 桥失败 → 样式页缩略图全消失且**刷新页面才好**（或一直不好）。
**`UNVERIFIED`：Node 桥瞬断是否真会发生、用户是否真见过空图 —— 未实测（禁 e2e）。**

**归横切**：**路径/文件名**（观测层的失败被缓存；与 39 号文「可忽略字段」同根：`''` 同时表示"拿不到"和"还没取"）。

**怎么修**：`catch` 里**不写缓存**（`cachedUserDir` 保持 `null`），或区分"永久不可用"（无 Node，记 `false`）与"这次失败"（不记，下次再试）。
⚠️ `/style` 是冻结页 ⇒ 只在它是 bug 时动，**另开轮次**。
