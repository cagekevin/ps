## 2. 证据：同一个形状，四种算法，五个数

对象固定为 `RepoRead<T>`（全仓唯一做到「失败臂取不到 `.value`」的形状）。三种算法今天实测：

| 算法 | 命令 | 今日实测 | 谁报过相近的数 |
|---|---|---|---|
| **A 类型名引用行数** | `git grep -n "RepoRead" -- src \| wc -l` | **47** | 解析卷 46、失败表达卷 46（10-25/10-26 时点） |
| **A' 只算带泛型的** | `git grep -n "RepoRead<" -- src \| wc -l` | **21** | 无人报过（说明大家用的是 A 不是 A'） |

## 3. 四个关键词的候选定义

> 下面是**候选**，不是裁定。每条给「定义 / 算法 / 反例（本仓已出现的错用）」。

### 3.1 「形状」

| 项 | 内容 |
|---|---|
| **定义** | 一个**类型**，它把「成没成」编进类型本身：判定成功后，失败臂在类型上取不到值。**同一条业务结论的多个类型算 1 个形状；同一个类型被多份卷引用只算 1 次** |
| **算法** | 按 `export type/interface` 定义处计数（不是引用行数），跨卷去重 |
| **反例** | 跨卷相加：19（失败表达）+ 6（持久化）+ 3（写落盘）+ 10（解析）+ 10（超时）= 48。其中 `RepoRead` / `LedgerRead` / `JsxOutcome` / `Decoded` 被 4 份卷各算 1 次、`CommandOutcome` 被 3 份卷各算 1 次 ⇒ **48 里至少 11 个是重复计数**，该数不成立 |

### 3.2 「入口」

**一个问题：「入口」在本仓被当 4 个不同的量用。**

| 用法 | 谁在用 | 数 |
|---|---|---|
| ① **函数定义**（导出几个写函数） | 写落盘卷 | 5（4 导出 + 1 内部） |
| ② **调用点**（多少个地方写盘） | 持久化卷 | 26 |
| ③ **族**（按「写失败 / 判失败 / 关失败」分组） | 失败表达卷 | 22 |
| ④ **去重生产者**（不按调用点，按源） | 用户文案卷 | 7 |

**候选定义**：判据「层数 = 形状数 = 入口数」里的「入口」应是 **①函数定义**——因为只有它能和「形状数」对齐（一个入口产一种形状）。
②③④ 另给名字：**调用点** / **族** / **生产者**，**禁止再叫「入口」**。

**反例**：写落盘卷 §0 写「入口数 5」，同一份卷 §1 写「24 个调用点」，持久化卷把 26 个调用点叫「写入口」。
⇒ 三份卷的「入口」分别是 5 / 24 / 26，**没有任何一份错**，但合读即矛盾。

### 3.3 「消费点」

| 项 | 内容 |
|---|---|
| **定义** | 消费某形状的**判别位置**数：取值前必须先判判别位的那一处 |
| **算法** | **必须二选一并写明**：`A 类型名引用行数` 或 `B 判别式行数`；C/D 需另起名字（引用文件数 / 调用点数） |
| **反例** | §2 的 5 个数；以及失败表达卷报 `JsxOutcome` 34，而算法 A 是 38 —— 差 4 无人说明 |

### 3.4 「判别语法」

**问题：「判别语法」被两个不同的东西占了同一个数字 13。**

| 卷 | 它数的 | 数 |
|---|---|---|
| 失败表达卷 | 同一句「成没成」的写法（`ok` / `status` / `kind` / `fail` / throw / null 判 / 谓词 / `??` 默认值…） | **13** |
| 类型收窄卷 | 「把宽类型收成窄类型」的语法（`as` / `as unknown as` / `!` / `satisfies` / `<T>x` / 谓词 / `typeof` / `instanceof` / `in` / `Array.isArray` / filter 谓词…） | **13** |
| 解析卷 | 同上「成没成」的写法，但只数了自选的 10 个字段名 | **6** |
| 写落盘卷 | `throw` / `ok:boolean` | **2** |
| 持久化卷 | `kind` / `ok` / `status` / 无判别位 | **4** |
| 用户文案卷 | `msg` 的几种书写位置 | **5** |
| 浮层关闭卷 | 「判别位根本不存在」（`open: boolean`） | **0** |

**候选定义**：**「判别语法」只指「同一句成没成怎么表达」**；类型收窄卷那一套改名 **「收窄语法」**。
两条命名分开后，13 与 13 不再互相暗示。→ 6 个数里 **2 个（失败表达 / 解析）可合并为 1 条口径**，其余 4 个是别的量。
