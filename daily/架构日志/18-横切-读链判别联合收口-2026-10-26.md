## 0. 一句话

**读链域（观测 → 语义 → 仓库）把判别位从 3 套（`ok` / `kind` / `status`）收成 1 套（`status`），取值词表从 3 套收成 1 套（`ok` / `notSeen` / `error`）。**

## 2. 表 C · 判别语法种数（"这次读成没成 / 坏在哪"的写法去重后）

读链域现状 **9 种**：

1. `ok` 布尔真假判断（A4）
2. `status === 'ok'`（A1）
3. `status === 'notSeen'`（A1）
4. `status === 'error'`（A1）
5. `kind === 'ok'`（A2）
6. `kind === 'absent'`（A2）

**9 → 5**。

## 5. 四层归属（谁兼职）

| 层 | 该干什么 | 现状 | 收口后 |
|---|---|---|---|
| 观测层（读原语） | 只报观测 + 原因，**不报结论** | ✅ 已合规（`fs-read.ts` 只有 status 三态） | 不变 |
| 语义层（数据层解析） | 把三态映射成各仓库语义 | ⚠️ **用 `kind` 自造了第二套词表**（`absent`/`bad`） | `status` + `notSeen`/`error` |
| 仓库层（对外形状） | 给消费点一个判别联合 | ⚠️ **用布尔 `ok` 自造第三套语法** | `status` 枚举 |
| 消费点（stores/commands/pages） | 只转发、只判判别位 | ✅ 不猜、不补 | 写法统一 |

**兼职点 = 语义层与仓库层**（各造了一套判别位）。这就是 ADR-0026 判据③前半句「每层用自己的词汇」许可出来的坏结构 —— 本轮把**判别位与词表**收成一份，**形状仍分层**（各层臂数不同是有意的：仓库层把"首次使用"折成"可用 + 默认值"，不许为了统一拉平）。

## 6. N → 1 前后数（**已回填 · 实测**）

| 口径 | 改前 | 改后 | 复现命令 |
|---|---|---|---|
| 读链域判别位名 | **3**（ok / kind / status） | **1**（status） | `git grep -n "\.kind\s*===\s*'ok'\|'\.kind\s*===\s*'absent'" -- src` → 改前 18 处 / 改后 **0** |
| 读链域取值词表 | **3** 套（{ok,notSeen,error} / {ok,absent,bad} / {ok,none,error}） | **1** 套（{ok,notSeen,error}） | `git grep -n "'absent'" -- src` → 改前 4 处 / 改后 **0**；`status: 'none'` 只剩**云台账自己的** 2 处（非读链） |
| 判别语法种数（读链域） | **9** | **5** | 见 §1 表 C |
| 消费点改动处 | — | **约 90 处 / 20 文件** | `git diff --stat -- src/cep src/stores src/commands` |
| 判别位定义处 | 4 | 4（位置不变，词表统一） | — |
| **`RepoRead.ok` 判别位** | 布尔（真/假两态） | **枚举（成功/出错）** | `git grep -n "read\.ok\|Read\.ok" -- src` → 改前 60 处 / 改后 **0** |

**为什么仓库层用枚举不用布尔**：布尔只能「成 / 不成」，装不下第三态；读链域的第三态（查不到）在仓库层被折成「可用 + 默认值」，但**折之前的语义层必须是三态** —— 枚举能承载，布尔不能。

### 6.3 零炸三问（逐条必答）

1. **哪些行为被改了？** 用户可感知的行为**零变化** —— 判别位改名不改变任何分支结果；唯一的行为差异是**类型层**：仓库层成功臂现在必须写判别位（漏写编译不过），失败臂的默认值来源不变。
2. **改前能走的路径，改后仍能走吗？** 走 —— 1080 条用例全绿（其中 8 个测试文件的 mock 造的是旧形状，同批改成新形状；这是**测试跟着接口改**，不是行为变了）。
3. **改前会失败的，改后仍失败吗？** 仍失败 —— `npm test` 全绿说明没有用例被"顺手改好"；失败的 13 条（4 文件）全部来自**测试 mock 造旧形状**（我的改动引起），已同批修；`fs-atomic-bytes` 的 7 条是**另一会话**的中间态，与本刀无关（我没碰 `disk-write.ts`）。
