## 一、改了什么

### ① `err` 判定：4 处散落 + 两套口径 → 2 处各管一套

| 原状 | 位置 | 口径 |
| --- | --- | --- |
| `ok: !(err === 1)` | `utils/jsx-result.ts:43` | 只有 `err === 1` 算失败 ⇒ `err=2` / `-1` / `NaN` **被当成功** |
| `result.err !== 0` | `cep/dialog.ts:23` | CEP **原生** fs API 口径 |
| `result.err !== 0` | `cep/dialog.ts:30` | 同上 |

改后：
- **jsx 侧**：`utils/jsx-result.ts` 一处 —— `err === 0` 成功；其余一律失败；`err` 不在 `{0,1}` 内还要说明
  （`宿主返回未知状态 err=…`）。判据集合 `KNOWN_JSX_ERR = new Set([0, 1])`。
- **CEP 原生侧**：`cep/dialog.ts` 一处 —— `isCepOk(err) = err === 0`，注释写明**它与 jsx 不是同一套契约**，不许合并。

### ② 成功哨兵：3 处 → 1 份集合

`EMPTY_STRINGS`（`''` / `ok` / `OK` / `undefined`）原来在 `utils/jsx-result.ts` 定义，但
`cep/transport.ts:187` 自己写了一遍 `raw === 'ok' || raw === 'OK'`、`cep/ps.ts:38` 写 `loadRes !== 'OK'`。

改后：集合只留 `utils/jsx-result.ts` 一份，导出两个谓词：
- `isJsxEmpty(raw)` —— `''` / `'undefined'`（**映射**：`undefined`）
- `isJsxOkSentinel(raw)` —— `'ok'` / `'OK'`（**映射**：原值）

两条映射语义不同（空 → undefined，ok → 原值），所以是两个谓词而不是一个 if。
`transport.ts` 与 `ps.ts` 都改调它们，`grep "'OK'" src/cep` = **0**。
